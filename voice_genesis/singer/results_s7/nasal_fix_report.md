## 2. 較正: 振幅ディップ

/w/ 基準（さくら「みわたす」、無修正）実測 **-9.33dB**（ディップ無し）に
対し、/n//m/ の振幅ディップ実測:

| 条件 | インスタンス1 | インスタンス2 |
|---|---|---|
| 旧実装(v1) | -9.27dB（**/w/とほぼ同値、弁別不能**） | 2.89dB（弱い） |
| voicing=0.30 | 0.98dB | 14.23dB |
| voicing=0.20 | 3.79dB | 17.35dB |
| **voicing=0.15（採用）** | **5.55dB** | **19.36dB** |
| voicing=0.10 | 7.57dB | 21.73dB |

**閾値 X=5.0dB（S6の/r/検査と同一値を継承）**。旧実装の一方のインスタンス
が /w/ と実質同じディップ量だったことが、耳判定「な→わぁ」の直接的な
物理的根拠として確認された。voicing=0.15 は両インスタンスとも閾値を
クリアする最も保守的な（ディップが浅い側の）値として採用。

## 3. 較正: 鼻音スペクトル（高域減衰比）

閉鎖区間の高域(≥3000Hz)エネルギー比 / 後続母音の同エネルギー比:

| 条件 | インスタンス1 | インスタンス2 |
|---|---|---|
| 旧実装(v1) | 0.254 | 0.381 |

**閾値 ≤0.60（実測較正・凍結）**。両実装とも数値上は0.60を下回るが、
新実装は旧実装よりさらに大きく下回り、鼻腔経由の高域減衰という物理的に
妥当な方向へ明確に改善している。

実害は無いが、検査自体は未検証のまま）。最終4音源での通過状況:

### identity 計測（S5/S6 と同一の8チェック matrix）— **非退行未達**

| 歌手 | vs 曲 | E1 | E2 |
|---|---|---|---|
| genesis3 | vs sakura | 0.4025 < 0.1071 → **不成立** | 0.0751 < 0.0930 → 成立 |
| genesis3 | vs umi | 0.4025 < 0.1521 → **不成立** | 0.0751 < 0.2114 → 成立 |
| voiceC | vs sakura | 0.1230 < 0.1071 → **不成立** | 0.0344 < 0.0930 → 成立 |
| voiceC | vs umi | 0.1230 < 0.1521 → 成立 | 0.0344 < 0.2114 → 成立 |

**結果: 5/8（S6の6/8を下回った。「S6の6/8を下回らないこと」の非退行
条件は未達）**。

**根本原因の切り分け（実測で特定）**: /r//h/修正の時（S6）と異なり、
今回は鼻音修正の**3要素（振幅ディップ・反共振ノッチ・高域減衰）のいずれ
単体でも** voiceC の within-singer/cross-song E1 距離を 0.0723（S6基準）
から 0.107〜0.122 まで押し上げることを確認した:

| 条件 | voiceC within-singer E1(a_c) |
|---|---|
| 修正なし（S6基準） | 0.0723 |
| 振幅ディップのみ | 0.1223 |
| 反共振ノッチのみ | 0.1071 |
| 高域減衰のみ | 0.1174 |
| 全部（最終, v3） | 0.1230 |

/n//m/ は「さくら」「うみ」双方に頻出する音素であるため、その音響的
実現をどう変えても（3要素どれか1つだけでも）集約 embedding が大きく
動いてしまう、という構造的な緊張関係が存在すると考えられる（S6での
助詞オーバーライドの発見と同型の教訓: 聴感上必要な修正が集約embedding
の安定性とトレードオフになるケース）。

**判断**: 耳判定で明確に「別バグ」と指摘された /n/→/w/ 縮退は実際の
音響ディップの実測比較（§2、旧実装が/w/とほぼ同一のディップ量だった
インスタンスの存在）により実在の欠陥と確認されており、これを是正する
ことを優先した。非退行未達（5/8）を隠さず報告する。
