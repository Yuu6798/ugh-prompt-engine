# R0.9 設計メモ — Phase 2 仮想変種「日本語で歌わせる」（VG-020 + VG-011）

ゴール: 設計書 Phase 2 Stage Gate「簡単な歌詞・メロディで歌声として成立
（日本語）」への到達。学習ベース R1 は本環境で実行不能のため、**学習なし・
決定論・可読 DSP のみ**で到達可能な上限を実装する（R0.9 と呼ぶ）。
配置: scratchpad `singer/` 配下。vt_harness/ と proto1/ は読み取り・import
のみ（変更禁止）。リポジトリは読み取り専用。補充判断は underspec_log_s1.md。

## S1. 励振の置換 — 声帯パルスモデル

R0.1 の加算正弦波スタックを、**ピッチ同期の声帯パルス列**に置換する:

- パルス形状: Rosenberg / 簡易 LF 系（開区間・閉区間比 = open quotient を
  パラメータ化）。genome.source.tilt が open quotient / パルス鋭さに写像され、
  スペクトル傾斜として現れること（写像は可読な式で実装し、実測 tilt との
  対応を確認する）
- jitter（周期ごとの周期揺らぎ）+ shimmer（周期ごとの振幅揺らぎ、新設。
  genome.microprosody に shimmer_amount を追加し物理事前分布 [0, 0.1]）
- **呼気ノイズは声門周期に同期して振幅変調**する（開区間で強く）。
  breathiness の Genome 契約（応答関数・0.95 クランプ）は維持
- エイリアシング対策必須（パルス列は広帯域。帯域制限パルス or
  オーバーサンプリング + デシメーション。aliasing test を通すこと）

## S2. 調音層 — 日本語 5 母音 + 最小子音集合

- 母音フォルマント目標表（/a i u e o/ × F1–F4 + 帯域幅）を凍結定数で定義。
  genome.resonance.formant_scale / offsets は目標表への乗算・加算として作用
  （Genome 契約の維持）
- 子音（題材曲に必要な最小集合）:
  - /s/ 無声摩擦（4–8kHz 整形ノイズ）
  - /k/ /t/ 無声破裂（閉鎖 30–50ms + バースト 10–20ms）
  - /g/ 有声破裂（短閉鎖 + 有声バー + バースト）
  - /r/ 弾き音（20–35ms の閉鎖近似 + 素早い F3 ディップ）
  - /m/ /n/ 鼻音（低域マーマー、F1≈250Hz + 反共振近似）
  - /w/ /y/ 渡り音（フォルマント遷移のみで表現）
- **コアーティキュレーション**: 音素境界でフォルマント目標を 40–80ms の
  時定数で補間（フレーム単位の時変フォルマントフィルタ。クリックなし・
  決定論を要件とする）

## S3. VG-020 — かな→モーラ→音素 frontend

- `singer/phoneme_jp.py`: ひらがな列 → モーラ列 → 音素列（子音+母音の組）。
  拗音・長音「ー」・撥音「ん」は題材曲に必要な範囲で対応（長音 = 母音持続、
  「ん」= /N/ 鼻音モーラ）。対応表は凍結 fixture としてテスト付き
- モーラ→ノート割当: 1 モーラ = 1 ノート（メリスマ・促音は本段階で扱わない。
  扱わない旨を明記）

## S4. VG-011 — Score+Lyrics レンダラと Performance 層

- `singer/score.py`: (midi, duration_beats, mora) の列 + tempo で曲を定義
- 題材（凍結）: パブリックドメイン俗謡「さくらさくら」冒頭 2 フレーズ
  （さくら さくら やよいの そらは みわたす かぎり — 概ね 8 小節、
  伝統的旋律 A-A-B... を 4 分音符基準で採譜。採譜内容は memo 逸脱不可、
  実装時の音高列は underspec_log に明記）
- Performance 層（Genome とは分離した演奏時パラメータ、§6.2 の表現分離）:
  - レガート: ノート間 F0 ポルタメント 40–70ms（歌詞が連続する場合のみ）
  - ビブラート onset 遅延 ~150ms（ノート頭では掛けない）
  - フレーズ強弱: フレーズ単位の緩やかな音量アーチ + フレーズ末減衰
  - フレーズ間ブレス: 200–300ms の休止 + 軽い吸気ノイズ（省略可）
- 出力: voice_A / voice_B（proto1 の genome 表現から bridge 経由で導出した
  2 声）× 同一曲。`singer/results_s1/sakura_voiceA.wav` / `sakura_voiceB.wav`

## S5. 機械前提条件（凍結ゲート。人間聴取の前段）

1. **音高追従**: 有声母音核（子音・遷移部を除く各ノート中央 50%）の
   F0 中央値が楽譜値から median ≤ 50 cents、全ノート ≤ 100 cents
   （測定は measure_v3 強化推定器）
2. **plausibility**: 母音核の periodicity r_median ≥ 0.35（全ノート違反 0）
3. **子音の実在**: /s/ /k/ /t/ 区間で高域エネルギー比 or スペクトル
   フラックスが隣接母音比で有意に上がること（子音が「鳴っている」ことの
   機械確認。閾値は実装時に設定し記録）
4. **決定論**: 同一入力 2 回レンダで波形 hash 一致
5. **aliasing**: >0.45×sr エネルギー比 < -40dB（S1 の広帯域化に対する再検査）
6. **grip 非退行クイックチェック**: R0.9 の持続母音経路で breathiness /
   vibrato_depth の 2 軸 grip を再測し、gate（≥3.0 ∧ dir≥0.90 ∧ E≥2.0）
   維持を確認（新励振で Genome 契約が壊れていないことの証明。
   formant/tilt 軸は R0.9 の写像変更があるため参考測定のみでよい）

## S6. 最終判定の手続き

機械前提条件 1–6 を全通過した WAV のみを「Phase 2 ゲート判定素材」として
ユーザーに提示する。**「歌声として成立」の判定者はユーザーの耳**（本試作で
初めて可能になる「耳上」検証）。機械条件が通らない場合は通るまで改修し、
通せない場合は fail-closed で記録・報告する。
