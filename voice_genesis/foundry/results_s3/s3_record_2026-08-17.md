## 2. 環境決定論の教訓（本 run の主要副産物）

同一入力 → 同一バイトの契約を破る環境因子を 2 つ実測で特定し、契約に組み込んだ:

1. **ffmpeg 版**: 44.1kHz 変換バイトは libavformat 60.16.100（6.1.x）に依存。
   7.x はヘッダ（Lavf 文字列）、5.x 以前は PCM 自体が不一致（版感度プローブ実測）
2. **numpy SIMD dispatch**: d3_sustain seed=701 が 1/1,524,000 サンプル・1 LSB
   だけ X86_V4/X86_V3 で分岐。tripwire（seed=11）はこの境界を踏まない盲点。
   → `NPY_DISABLE_CPU_FEATURES=X86_V4` + 4 ゲート（版 pin / SIMD assert /
   罠確認 / cache 来歴）を runbook §2.2 に凍結（PR #266・全採用 7 件）

## 5. 効果帰属（S3 の中心成果）

**帰属の限界（先に明示）**: run 4 は run 3 に対して **D3 追加と user 話者追加の

因果帰属することは本 run 単独では**原理的に不能**（多重介入の交絡）。以下の
判定はすべて「交絡下の方向性評価」であり、因果確定は D3 単独 / user 単独の
ablation（Q7）を要する。

| 仮説 | 判定 | 根拠 |
