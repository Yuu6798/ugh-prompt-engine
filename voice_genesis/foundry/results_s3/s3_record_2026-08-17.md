## 2. 環境決定論の教訓（本 run の主要副産物）

同一入力 → 同一バイトの契約を破る環境因子を 2 つ実測で特定し、契約に組み込んだ:

1. **ffmpeg 版**: 44.1kHz 変換バイトは libavformat 60.16.100（6.1.x）に依存。
   7.x はヘッダ（Lavf 文字列）、5.x 以前は PCM 自体が不一致（版感度プローブ実測）
2. **numpy SIMD dispatch**: d3_sustain seed=701 が 1/1,524,000 サンプル・1 LSB
   だけ X86_V4/X86_V3 で分岐。tripwire（seed=11）はこの境界を踏まない盲点。
   → `NPY_DISABLE_CPU_FEATURES=X86_V4` + 4 ゲート（版 pin / SIMD assert /
   罠確認 / cache 来歴）を runbook §2.2 に凍結（PR #266・全採用 7 件）

## 5. 効果帰属（S3 の中心成果）

**帰属の限界（先に明示）**: run 4 は run 3 に対して **D3 追加と user 話者追加の
2 介入を同時に**加えたゼロから再学習であり、観測された改善・劣化を単一介入へ
因果帰属することは本 run 単独では**原理的に不能**（多重介入の交絡）。以下の
判定はすべて「交絡下の方向性評価」であり、因果確定は D3 単独 / user 単独の
ablation（Q7）を要する。

| 仮説 | 判定 | 根拠 |
|---|---|---|
| D3 合成データは日本語破綻（り→ん系）を矯正する | **強い方向性示唆（交絡あり・未実証）** | 40K 耳判定 1（全面改善）。破綻矯正は D3 の機構的標的（音素文脈の合成被覆）であり user 追加からの説明は蓋然性が低いが、同時介入のため単独帰属は不能 |
| run 4 は run 3 に対し音質の代償を持つ | **劣化の実在は確定・発生源は未帰属** | 40K 耳判定 2（ノイズ混入・総合品質は run3 優位）。容疑は D3 の spk_id=0 併合（合成音響特性の混入）と user 宅録の双方（= Q7） |
| user 3.9 分で第三の声が立つ | **方向性陽性・確定保留** | 5K/10K/40K 一貫して「別の声の気配」。確定は user 固有の振幅不安定（さくら LRA 18.8→20.8 LU と持続・データ起因）が阻害 |
| 既存 2 話者の振幅安定性は劣化しない | 定量では成立（LRA で run3 同等以上）だが**耳は劣化と判定** | → §6 |

## 6. 評価器ギャップの記録（VG-E1 への直接教訓）

40K の LRA 定量比較（run4 が 4 アンカー中 3 で改善）から Claude は「劣化は
過渡」と一次判定したが、**User の耳は「ノイズ混入・区間レベル音量交絡で
run3 優位」と逆判定**した。LRA は変動幅しか測れず、ノイズ・区間レベルの
交絡を捉えない。**自動メトリクスと隠し評価器（耳）の乖離の実例**として
記録する — VG-E1 の評価軸語彙設計では「LRA 単独を品質 Gate にしない」
「スペクトルノイズ軸・区間レベル軸を含める」を要求事項とする。
