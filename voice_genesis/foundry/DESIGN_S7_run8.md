## 1. 何を測るか

### 1-1. 「話者依存」を再解釈する（本調査の出発点）

s6 record §5-3 は「破綻を起こさないのは pjs 系のみ = 話者依存」で止まっている。
話者を**学習データ中の実歌唱分数**に置き換えると単調に並ぶ:

| 話者 | 実歌唱データ | 実測値 | り→ん / 語尾破綻 |
|---|---|---|---|
| pjs | 実歌唱（PJS） | **26.86 分** | **なし**（唯一） |
| user | 宅録カード T0/T1/T2（全て歌唱） | **3.890 分**（ph_dur 233.395 s・有声 2.865 分＝171.88 s） | 部分的・run5→7 で改善進行 |
| ritsu | D2 = VCV **録音のみ・実歌唱ゼロ** | 0 分（VCV 自体は 33.4 分） | run5→7 一貫して破綻 |
| amitaro | 朗読のみ・持続音ゼロ | 0 分（recitation は 18.742 分＝ph_dur 1124.511 s） | 単体さくらで日本語破綻 |

- **総データ量では説明できない**（ritsu が最大量で最悪）。順序と一致するのは
  実歌唱分数だけ
- これは `DESIGN_S3_backfill.md`:23 の原因仮説（「VCV 録音のみで実歌唱ゼロが
  原因仮説」）と同じ立てであり、**D3（F1.4 合成歌唱 20 分）で埋める試みが
  効かなかった**ことが run 7 で確定した形。FOUNDRY_ROADMAP の既知所見
  「F1.4 レンダ出力は品質源泉に使わない」と整合する
- **ただしこれは仮説であって実測ではない**。n=4・話者と実歌唱分数が完全交絡で、
  本走行はこれを**因子分解して切り分ける**ことを目的とする

### 1-2. 実曲側の構造（さくら/うみ非対称の分解）

| 対象 | 譜面上の実体 | 尺（設計値） | 音高 | 耳判定 |
|---|---|---|---|---|
| さくら「かぎり」の**り** | `score.py:57` `(1, 4, 0)` = deg1・4 拍・phrase final | **3.333333 s**（72 BPM） | A3 = MIDI 57 = 220.0000 Hz | **破綻**（ritsu run5–7） |
| さくら「みわたす」の**す** | `score.py:56` `(3, 2, 0)` = deg3・2 拍 | **1.666667 s** | D4 = MIDI 62 = 293.6648 Hz | 語尾連続発声（pjs/user） |
| うみ 最長音 | `score_umi.py:41` `(62.0, 3.0)` = 3 拍 | **2.045455 s**（88 BPM） | D4 = 62 | **成立**（全話者） |

破綻する 2 セルは**最長かつ最低音**（り）と**次に長い**（す）であり、成立する
うみの最長音（2.045 s・D4・**鼻音 onset の「な」**）はその中間に挟まる。
したがって尺だけでも音高だけでも説明できず、**モーラ（子音種）を含む 3 因子**の
分解が要る。

### 1-3. 仮説

| ID | 仮説 | 反証条件 |
|---|---|---|
| H1 | 持続長が閾値を超えると崩壊する | 尺ラダーで単調性が出ない |
| H2 | 低音側で崩壊する（音域被覆の欠落） | 音高ラダーで差が出ない |
| H3 | 子音 /r/ または母音 /i/ に固有 | 「い」「る」で同等に崩壊する |
| H4 | **話者**で崩壊境界が動く | 4 話者で境界が同一 |
| H5 | 世代（データ構成）で境界が動く | run5/6/7 で境界が同一 |

**H4 の到達限界（明記）**: 本設計は話者内で**実歌唱分数を振らない**。
したがって H4 が成立しても言えるのは「**境界は話者で動く**」までで、
その原因が実歌唱分数なのか声質・録音条件・データ量・音域被覆なのかは
**識別できない**（§1-1 の完全交絡は本走行では解けない）。実歌唱分数へ
帰属するには exposure を話者内で振る介入が要る（§8 (a)）。

**H0（文脈依存性）**: フル譜面の該当区間と 3 ノート診断セルで軸値が一致するか
（§1-5）。不一致なら他の H の外挿可能性が制約される。

### 1-4. 因子ラダー（凍結）

- **持続長 D**（4 水準・さくら 72 BPM 基準）: 1 拍 = 0.833333 s / 2 拍 =
  1.666667 s / 3 拍 = 2.500000 s / 4 拍 = 3.333333 s
- **音高 P**（3 水準）: A3 = 57 = 220.0000 Hz（り の実音高・最低）/ D4 = 62 =
  293.6648 Hz（す の実音高）/ F4 = 65 = 349.2282 Hz（donor bank の高側 pitch dir・
  `score_d3_sustain.py` の high と同値）
- **モーラ M**（5 水準）: **り**（陽性・破綻既知）/ **い**（同母音・子音なし →
  /r/ の寄与を分離）/ **る**（同子音・別母音 → /i/ の寄与を分離）/ **す**
  （第 2 の既知欠陥）/ **な**（鼻音 onset = 崩壊先の音・陰性対照）
- **話者 S**（4 水準）: ritsu / pjs / user / amitaro
- **世代 G**（3 水準・cross-model と pre-mark）: `s4_run5_acoustic_v1` /
  `s5_run6_acoustic_v1` / `s6_run7_acoustic_v1`

### 1-5. 割付（設計値・実装側で独立検算すること）

診断スコアの 1 セル = **助走 2 音 + 対象音 1 音の 3 ノート 1 フレーズ**とし、
助走は「か（1 拍）ぎ（1 拍）」で、その音高を**対象音高の +7 / +5 半音**に固定する
（さくら「かぎり」の音程関係と同一 — `score.py:57` の deg4 = +7 / deg3 = +5 /
deg1 = +0 を対象音高基準で写したもの）。**音程跳躍を全水準で一定に保つ**ため
絶対音高で固定はしない。この設計の帰結として、**P = 57・M = り・D = 4 拍の
セルは さくら「かぎり」の譜面断片と同一**になる。

**ただしこれは「モデル入力が同一」を意味しない（H0・初版の誤りを訂正）**:
`gate_synth.run_pipeline` は `notes_raw` **全体**を 1 本のトークン列
（`v_tokens1 = [SP] + real_phones` 以下同様）へ符号化して dur / pitch /
acoustic の各 predictor に渡す（`gate_synth.py:1108-1133`）。したがって
3 ノートのクリップはフル譜面の末尾 3 ノートとは**別の入力**であり、
文脈依存の破綻はクリップ側で消えうる。よって:

- **H0（文脈依存性）を仮説として立てる**: 同一 (話者・モーラ・尺・音高) で
  「フル譜面の該当区間」と「3 ノート診断セル」の軸値が一致するか。
  一致しなければ**診断セットの外挿可能性そのものが制約される**ため、これは
  他の H に先立って裁定する
- **陽性対照は実曲側に置く**（§0-4）。診断セルは陽性対照ではない

単独ロングトーンでなく助走付きにするのは、文脈依存の破綻を取りこぼさない
ため（`score_d3_sustain.py` の単独ロングトーン様式とはここが違う）。

**辞書被覆の扱い**: 「る」は さくら/うみ のどちらにも現れないため正本辞書
（dsdict）での被覆が未確認。未収載なら**代用せず fail-closed で除外して
記帳**し、H3 の /i/ 分離は「い」のみで行う（`convert_*` の unmapped 除外と
同じ流儀）。

| ブロック | 割付 | セル数 |
|---|---|---|
| A: ritsu 全数 | 4 D × 3 P × 5 M（run 7） | **60** |
| B: 他 3 話者・境界近傍 | D ∈ {2 拍, 4 拍} × P ∈ {57, 65} × M ∈ {り, す, な} × 3 話者 | **36** |
| **B-ref: 他 3 話者の参照セル** | **D = 1 拍** × P ∈ {57, 65} × M ∈ {り, す, な} × 3 話者 | **18** |
| C: 世代軸（縮約） | ritsu・M = り・4 D × 3 P × run5/run6（run7 分は A に含む） | **24** |
| 合計レンダ数 | | **138** |

**B-ref を分離して数える理由**: `ref_band_l1`（§2-1）は同一話者・同一モーラ・
**同一音高の 1 拍セル**を参照として要求する。ブロック B は 2 拍/4 拍しか
持たないため、参照セルを明示的に割り付けないと**ブロック B の 36 セル全てで
`ref_band_l1` が計算できず**、§7 の「全セルに 5 軸値」が構造的に充足不能に
なる（初版の欠落）。ブロック A と C は 1 拍を内包するため追加不要。

## 2. 観測子（計器）の設計

### 2-1. 一次量（全て機構名・`PROVENANCE = "measured (score-informed sustain QC)"`）

対象ノートの**命令上の**区間（`gate_synth` の dur モデル出力から取得。
VG-L0 probe の `note_region_energy` / `_capture_durations` と同じ経路）を
onset を除いて前半 P1・後半 P2 に 2 分割し、既存計器
[`scripts/measure_bands.py`](scripts/measure_bands.py) の `band_shares()`
（Welch PSD 帯域比 6 帯 + `tilt_db_per_decade_1k_8k`）と `hnr_median_db()` を
**窓ごとに適用**して差分を取る:

| 軸 | 定義 | 崩壊時の期待符号 |
|---|---|---|
| `hi_share_delta` | P2 − P1 の（[1k,3k) + [3k,5k)）比 | 負（高域喪失） |
| `low_share_delta` | P2 − P1 の [0,500) 比 | 正（低域集中） |
| `tilt_delta` | P2 − P1 の `tilt_db_per_decade_1k_8k` | 負 |
| `hnr_delta_db` | P2 − P1 の `hnr_median_db` | 符号は未予測（事前登録: 予測しない） |
| `ref_band_l1` | P2 の 6 帯ベクトルと、**同一話者・同一モーラ・同一音高の 1 拍セル**（= 参照セル）の定常部ベクトルとの L1 距離 | 正に大 |

`ref_band_l1` だけは話者内で正規化されるため、話者間比較の交絡が最も小さい。

**残る交絡の pre-mark**: 助走は対象音高に対して固定度数で置くため音程跳躍は
一定だが、**助走の絶対音高は P とともに動く**（P = 65 では助走が F5 相当まで
上がる）。したがって「高音側で崩壊しない」が出た場合、それが対象音の音高に
よるのか助走を含むフレーズ全体の音域によるのかは**本走行では分離できない**
（H2 の裁定は `undetermined` を許す）。

### 2-2. 計器そのものへの制約

- **単一スカラーへ合成しない**（§0-6）。軸別に報告する
- 一次指標は `gate_synth` が record.json に残す**正規化前の生値**を使う
  （VG-L0 probe が踏み抜いた「ピーク 0.6 正規化後 RMS は実質クレスト
  ファクタ」の再演を避ける）
- 計測不能は例外でなく `status` 付きの記録（`measure_bands` の既存規約に従う）

### 2-3. 校正（事前登録）

1. **primary 軸の選定規則を先に凍結する**（どの軸が効くかは未知のため、
   軸ではなく**選定規則**を事前登録する）: 校正セット上で陽性/陰性の
   分離余裕（正規化した median 差）が最大の 1 軸を primary に採る。
   **選定は校正セットのみで行い、確認は hold-out セルで行う**
2. **耳ラベル**: 層化 24 セル（ritsu 12 / 他話者 4 ずつ）を**ランダム順・
   セル条件を伏せて** User に提示し、`break / borderline / ok` の 3 値で
   ラベル。24 を **calibration 12 / hold-out 12** に事前分割する
3. **無償の追加 hold-out**: run5/6/7 の既存判定材料（さくら「かぎり」の り・
   「みわたす」の す・うみ全体）には **s4/s5/s6 record に User の耳判定が
   既に付いている**。これを再ラベルなしの hold-out として使う
4. **成立条件**: primary 軸が hold-out で陽性/陰性を分離し、かつ §0-4 の
   陽性対照ゲートを通ること。**満たさなければ計器不成立を宣言して §8 の
   分岐 (d) へ進む**

## 3. レバー探索（追加収録なしで実行可能なもの・**計器成立が前提**）

User 追加収録が当面不可（§0 冒頭の裁定）のため、「実歌唱を増やす」介入は
本走行の射程外。既存資産だけで動かせるレバーを実測する:

| ID | レバー | 実装経路 | 位置づけ |
|---|---|---|---|
| L1 | 長音符の分割・フレーズ境界へのブレス挿入 | VG-L0 probe の `phrase_boundary_indices` / SP ノート挿入（実測で介入点確定済み） | スコア側の回避策 |
| L2 | 子音時間配分 `consonant_duration_scale` | 同 probe の `_DurOutputPatch`（**出力まで届くことを実測済み**） | 推論側の回避策 |
| L3 | 移調（+5 半音 等） | 音高ラダーの外挿・H2 が成立した場合のみ | 実用上の回避策 |
| L4 | **spk_embed 補間**（ritsu ⇄ pjs） | `gate_synth.find_speaker_embed` / `load_speaker_embed_vector` が返す 384 次元ベクトルの線形補間（S2 の補間候補生成と同型機構） | **診断としても強力**: 崩壊が補間比で単調に消えるなら「話者埋め込みが担っている」直接証拠になる |

**L4 の正直会計**: 補間は identity を動かす。破綻が消えても「ritsu の破綻が
治った」のではなく「別の声になった」であり、**緩和策としては代償付き**である
ことを結果に必ず併記する（第三の声の議論と混同しない）。

  少なくとも 1 セルで行う（VG-L0 の Render Reproducibility と同じ様式。
  同一プロセス内反復は independent replay の証拠にしない）
- 解析スタック = `ANALYSIS_STACK_PIN`（numba 0.66.0 / librosa 0.11.0 /
  pyloudnorm 0.2.0）と同一環境で実行し、`execution_profile` に記帳する
- **検算照合ゲート**（AGENTS.md §8）: 本書に埋めた設計値
  — 拍→秒（0.833333 / 1.666667 / 2.500000 / 3.333333 / 2.045455 s）、
  MIDI→Hz（220.0000 / 293.6648 / 349.2282 Hz）、セル数（60 / 36 / 18 / 24 / **138**）、
  実歌唱分数（26.86 / 3.889917 / 0 / 0 分）、amitaro 朗読 18.741850 分 —
  を実装側が**独立に厳密計算して照合**し、不一致（許容誤差 1e-4）は停止して報告する
