## 3. ライセンス会計

### 3.1 波音リツ本体（音源そのもの）

一次ソース: `http://www.canon-voice.com/kiyaku.html`（readme.txt 記載の規約 URL。
`s0_survey.md` が事前調査していた `terms/` と表記は異なるが同一規約ページ、http→https
リダイレクト確認済み）。

- **商用利用可**・**改変可**（個人利用の加工・改変は無条件、配布物としての改変も可）・
  **再配布可**（原音・加工後とも）・**クレジット表記不要**（明記）。
- **留保**: 規約全文に「AI」「生成」「学習」「DiffSinger」「機械学習」の語を含む一文が
  存在しない。DiffSinger（AI 歌声合成）利用は一般規約の射程内という解釈に依存し、
  本家による **AI 利用の明示的許諾文言は無い**（本家自身が DiffSinger 版を同一サイトで
  配布している状況証拠はあるが、規約文言上の断定はできない、という留保付き）。

→ **音源本体単体としては「条件付き yes」**（商用可・改変可・再配布可・クレジット不要、
ただし AI 明示条項なしの解釈依存という留保あり）。

### 3.2 vocoder（nsf_hifigan）— 商用可否を実質的に律速する要素

- `dsconfig.yaml` の `vocoder: nsf_hifigan` 参照どおり、zip には vocoder 本体は同梱
  されず、readme.txt の指示で OpenUtau 本体リポジトリの GitHub Release アセット
  （`xunmengshe/OpenUtau` タグ `0.0.0.0` の `nsf_hifigan.oudep`、実体は openvpi 製
  vocoder の再配布、55MB）を別途取得する必要がある。
- **ライセンス**: NOTICE.txt 逐語確認により **CC BY-NC-SA 4.0**
  （Attribution-NonCommercial-ShareAlike、OpenVPI Team 提供）。再配布条件として
  (1) 販売・課金禁止、(2) ライセンス本文またはリンクの同梱、(3) NOTICE 全文
  （謝辞リスト含む）の同梱、(4) fine-tune/改変時の変更点明記、が明記されている。

### 3.3 会計結論（商用パス律速）

- **リツ本体の「商用利用可」は、vocoder の NonCommercial 条項によって実質的に上書き
  される**。フルパイプライン（linguistic→dur→pitch→acoustic→vocoder）を通した最終
  出力音声は CC BY-NC-SA 4.0 の vocoder モデルを経由するため、**フルパイプライン
  成果物は当面非商用律速**と判断する。
- **商用パスの選択肢**（S0 時点で列挙のみ、実施は S1 以降の設計判断）:
  1. P2（`FOUNDRY_ROADMAP.md` Phase 地図）で vocoder を自前学習し、商用可ライセンス
     の学習データ・成果物として置き換える。
  2. MIT 系等の商用可 vocoder への差し替え（既存 community vocoder の選定調査が
     別途必要）。
- **前例との整合**: 本件は `docs/musicgen_backend.md` が記録した MusicGen 重み
  （CC-BY-NC-4.0、非商用条項）の扱いと**同型のライセンス会計パターン**である
  （「本体トラックは条件付きで使えるが、一部コンポーネントの NC 条項が下流成果物の
  商用利用を律速する」という構造）。同ドキュメントの前例を踏襲し、現時点では
  「非商用スコープでの利用は問題なし・商用化は別途対応」という扱いとする。

## 4. 推論スパイク（フル配線・CPU・決定論）

一次ソース: `s0_probe_record.md`（`build_probe.py`、scratchpad 完結）。

- **経路**: フル配線（linguistic→dur→linguistic→pitch→acoustic→vocoder の 5 モデル
  全通過、手作業フォールバック不使用）。入力構築は OpenUtau C# ソース
  （`stakira/OpenUtau` の `DiffSingerBasePhonemizer.cs`/`DiffSingerPitch.cs`/
  `DiffSingerRenderer.cs`/`DiffSingerUtils.cs`）を一次典拠として Python へ忠実に移植。
- **題材**: 「さくらさくら」冒頭2フレーズ（6モーラ）、`voice_genesis/singer/score.py`
  の凍結済みスコアを read-only import。
- **所要時間**: モデルロード込み **24.6 秒**（CPU、5 モデル、`onnxruntime==1.28.0`
  `CPUExecutionProvider`）。acoustic（shallow diffusion 20 step 相当）と vocoder が
  支配的（各 7〜12 秒）。
- **決定論**: `onnxruntime.set_seed(42)` + intra/inter_op_num_threads=1 固定で、
  独立 2 プロセス実行が sha256 完全一致（`42f459d5ec27b4b4b036a7e6415a93beabf5549e1943324a94fa88eb1f119b98`）
  を確認済み。
- **出力**: `s0_sakura_probe.wav`（44100Hz, PCM16, 303,104 samples = 6.873秒、
  PEAK_NORM=0.6 正規化後 peak=0.6/RMS=0.1136）。**WAV 本体はリポジトリへ非コミット**
  （sha256 + 再生成手順で担保。再生成スクリプト: scratchpad
  `s0_ritsu_diffsinger/build_probe.py`、入力の zip/vocoder も同 scratchpad 配下に
  保存済み、必要な際は同スクリプトの再実行で再現可能）。
