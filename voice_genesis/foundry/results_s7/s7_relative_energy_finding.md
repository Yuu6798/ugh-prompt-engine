# 相対エネルギーでは経路床と本物の終端を分離できない（2026-08-22 実測）

1.1 の診断（`s7_0b_remeasure_1_1.json`）で voicing 3 軸が **8/10 群で床側に縮退**した
原因を、推測で終わらせずに直接測った。結論:

> **経路床（SP のみのレンダ）の相対エネルギーは、本物の終端の中央値より大きい。**
> したがって相対エネルギー閾値では、この 2 つを**原理的に分離できない**。
> 閾値調整の問題ではない。

## 1. 実測（終端窓 RMS / ノート核 RMS）

同一レンダ内の比なので線形 gain に不変な量である（1.1 の energy gate が使う量そのもの）。

**本番セル（`position = final`・全 10 群・n = 320）**:

| 分位 | 比 |
|---|---|
| p05 | 0.016 |
| p25 | 0.111 |
| **p50** | **0.207** |
| p75 | 0.386 |
| p95 | 0.628 |

**校正刺激**:

| 刺激 | 比 |
|---|---|
| `rr_clean_terminal_ri`（正常な終端 /ri/） | 0.206 |
| `rr_long_tail_000` | 0.222 |
| **`rr_silence`（経路床 = SP のみ）** | **0.319** |
| `rr_long_tail_040` | 0.351 |
| `rr_long_tail_080` | 0.536 |
| `rr_long_tail_160` | 0.689 |

## 2. 何が起きているか

**経路床 0.319 > 本番中央値 0.207**、かつ **経路床 0.319 > 正常終端 /ri/ 0.206**。
順序が**逆転している**。

したがって:

- 床を落とす（`production_range_resolution` の floor 要件）には **τ > 0.319** が要る
- しかし τ = 0.5 は本番セルの **84%（270/320）を無声に落とす**（0.5 を超えるのは 16%）
- τ を 0.319 未満に下げれば床が voiced として通り、**1.0 の天井飽和へ戻る**

**逃げ場が無い。** 1.0（energy gate 無し）は天井、1.1（τ=0.5）は床。その中間の τ は
「床を通す」か「本物を落とす」かのどちらかにしかならない。

## 3. なぜ校正では通ってしまったか

梯子 `rr_long_tail_080` / `160` の比は **0.536 / 0.689** で、本番セルの p75〜p95 に相当する
**大振幅の終端**である。梯子は「終端に核と同程度の振幅の有声を注入する」作りなので、
**本番の終端破綻（減衰しながら残る）とは振幅の質が違う**。

つまり校正セットは**振幅の次元で本番を代表していない**。1.0 は床刺激が voiced 判定
されやすすぎて落ち、1.1 は梯子刺激が床と離れすぎていて通った。どちらも検出器の性質
ではなく**校正セットの性質**である。

## 4. 帰結

- **TRF measurement spec / 1.1 の production applicability = NOT_ESTABLISHED / DEGENERATE
  （床側）**。1.0 と同じ扱いで sidecar に記帳する（1.1 の凍結値は書き換えない）
- **fresh confirmation set をこのまま作らない**。同じ理由で Gate 1 が裁定不能になるだけで、
  レンダ費用を払う意味が無い
- **`production_range_resolution` 要件自体は間違っていない**（本番で飽和しない検出器を
  要求するのは正しい）。間違っていたのは、**その要件を相対エネルギー 1 次元で満たそうと
  した候補空間**の方である

## 5. 次に効きそうな軸（実測に基づく仮説・未検証）

床は「**命令音高ちょうどの純粋な調波ブザー**」である（`s7_b1_pipeline_silence_diagnostic.json`:
終端窓の主周波数 256.7 Hz vs 命令 C4 = 261.6 Hz、有声フレーム率 0.859）。
一方、本物の終端は**フォルマント構造を持ち、f0 が命令値から離れていく**。したがって
エネルギーではなく**スペクトル形状・調波の素性**で分離できる可能性がある:

- 終端窓の mel 形状と**ノート核の mel 形状**との距離（power 比ではなく shape 距離）
- f0 の命令値からの乖離・時間的な不安定さ
- スペクトル平坦度 / フォルマント帯のエネルギー比

**これは仮説であって、まだ 1 つも測っていない。** 候補空間を作るなら事前登録が先である。

## 6. 言っていないこと

- 「TRF が測れない」とは**言っていない**。測れないと分かったのは
  **相対エネルギー 1 次元の voiced detector**である
- 「この pipeline では終端破綻を観測できない」とも**言っていない**。§5 の他の軸
  （mel 持続・HNR・vowel drift）は縮退していない
- 「1.1 が失敗だった」とも**言っていない**。1.1 は ringing 基準を 10/10 群で回復させ、
  §5-0 の意味論改訂を不要にした。分解能の問題だけが残っている
