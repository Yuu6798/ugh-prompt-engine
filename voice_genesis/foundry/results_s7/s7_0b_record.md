## 1. 帰結の全数（AC の達成条件）

| | |
|---|---|
| 記帳セル数 | **360 / 360** |
| `rendered` | **360**（`dropped` 0 / `not_run` 0） |

| GPU 費用 | **$0**（全て CPU レンダ） |

§11 AC の達成条件は「360 セル全てがレンダされたこと」ではなく「360 セル全ての
**帰結**が記帳されたこと」だが、今回は結果的に全数レンダできた。

## 2. Gate へ入れられる群は **0/10**（§5-0 の ringing 規則による）

事前登録の規則は「終端窓の `voiced_frames == 0` を**機械検査**で満たしたレンダ
だけを ringing 基準の母集団に入れ、評価対象セル自身は leave-one-out で除外する。
群に 1 つでも補正不能があれば群ごと Gate から外す」。実測:

| | |
|---|---|
| `tail_voiced_frames == 0` のセル | **4 / 360** |
| それが出た群 | run5/user・run6/user・run7/pjs・run7/user（**各 1 セル**） |
| そのセルの正体 | **すべて `P-ANCHOR|umi|final`**（うみ譜面の発話末「な」） |
| 残り 6 群 | 0 セル |
| 結果 | **全 10 群が `ringing_uncorrected_group`** |

内訳の意味:

- 0 セルの群 → 基準母集団が空 → 全セル補正不能
- 1 セルの群 → **そのセル自身が leave-one-out で基準を失う** → 1 セル補正不能 →
  群ごと除外。これは §5-0 が「起こりうる」と名指しした非対称そのものである
- 群を救うには**同一群に 2 セル以上**の無声通過レンダが要る

> 訂正: 中間報告で「無声を満たすセルは 1 つも無い」と書いたが、正しくは
> **4 セルある**（いずれも同一の umi アンカー）。結論（0/10 群）は変わらない。

## 3. 主観測 4 軸のうち 3 軸が本番セルで縮退・床張り付き

ε は凍結 spec の値（ms 軸 10、`tail_f0_persistence` 0.0333、mel 0.0387）。

| 軸 | 群内 MAD の範囲 | `degenerate_axis`（MAD=0）の群数 | 判定 |
|---|---|---|---|
| `excess_tail_voiced_ms` | 0 – 10 | **3 / 10** | 残りも MAD = 0.5–1 hop（= ε 以下） |
| `release_after_score_boundary_ms` | 3.33 – 10 | 0 / 10 | **全群で MAD ≤ ε**（ばらつきが測定床以下） |
| `tail_f0_persistence` | 0 – 0.083 | **8 / 10** | 縮退が既定 |
| `terminal_mel_persistence` | 0.00046 – 0.105 | 0 / 10 | 唯一 36/36 の異なり値。ただし **MAD > ε は 2/10 群だけ** |

§7-0 (0)（MAD == 0 の軸は primary 候補から外す）と §7-0 (2b)（primary は B-1 で
凍結された 4 軸に限る）を合わせると、**primary に立てられるのは実質
`terminal_mel_persistence` 1 本**になる。

そしてその 1 本も、話者内 3 対照（§5-1）を population で見ると:

| probe（final・全 10 群） | n | median | IQR |
|---|---|---|---|
| P-RI-FINAL | 90 | 0.0067 | [0.0006, 0.0451] |
| P-I-FINAL | 90 | 0.0084 | [0.0022, 0.0438] |
| P-N-FINAL | 90 | **0.0357** | [0.0080, 0.1191] |

`/N/` が最も高い（鼻音の終端持続は実際に大きい）という**向きは期待どおり**だが、
`median(ri) - median(N) = -0.0290` は **ε = 0.0387 より小さい**。すなわち
**期待される最大の対照差すら、自分の測定床を下回る**。

## 4. 機構（なぜこうなるか）

B-1 で記帳した経路と同一である（[`s7_finding_sp_padding_f0.md`](s7_finding_sp_padding_f0.md)）:

```
commanded score boundary → TAIL_FRAMES=8 の SP → pitch predictor が SP にも F0
  → NSF source-filter vocoder が調波音源を励振 → 境界後も常に「有声」
```

主観測 3 軸はいずれも「境界後に有声が何 ms 残るか」を数える。上の経路により
**本番セルは一様に天井へ張り付く**（`tail_f0_persistence` = 1.000 が既定値）。
B-1 の校正梯子は有声のはみ出し量を**物理的に変えていた**ので候補を弁別できたが、
本番セルはその可変域の外にいる。**校正が通ったことと、本番で分解能があることは
別である** — 今回それが実測で分かれた。

## 6. 言っていないこと（主張上限）

- 「Gate 1 が不合格だった」とは**言っていない**。耳ラベルが無いので**合否が存在しない**
- 「TRF が本番セルで無効だ」とも**言っていない**。無効と分かったのは
  **主観測 3 軸の現行操作化がこのレンダ経路で分解能を持たない**ことである
- 「モデルが破綻していない」とも**言っていない**。計器が天井に張り付いているとき、
  破綻の有無は測れない
- 補助軸（HNR / vowel_drift / energy_decay / 3 対照距離）は全セルで記録済みだが、
  §7-0 (2b) により **primary には使えない**（B-1 で凍結されていない）

## 7. User 裁定が要る 1 点

現状のまま進むと **Gate 1 は構造的に裁定不能**（Gate 対象群 0、primary 候補 1 本、
その 1 本も対照差 < ε）。選択肢:

- **(A) `ringing` 基準の母集団定義を amendment する** — 「機械検査で無声だったレンダ」
  から「**事前登録した対照レンダ**（例: SP のみのレンダ = 経路の床）」へ。
  群あたり 2 本の追加レンダで leave-one-out が成立する。
  ただし SP のみのレンダは**無声ではない**（B-1 で実測済み）ので、これは
  「無声対照」から「**経路床対照**」への**意味の変更**であり、黙って行えない
- **(B) 現行規則のまま Gate 1 を `undetermined`（理由コード
  `ringing_reference_unobtainable`）で閉じ、8-B へ進まない** — 事前登録の fail-closed
  どおりの帰結。**本記録の既定はこれ**
- **(C) B-1 を再開し、絶対エネルギー床を持つ voicing 候補を含む候補空間で
  測定仕様を作り直す** — 凍結したばかりの `1.0` を差し替えることになる。
  §3 の飽和は候補の性質（pyin に床が無い）に由来するので、原理的にはここが本丸
- **(D) 測定窓・境界の意味論を変える**（例: 終端窓を短くする / 母音終端を基準にする）
  — 同じく凍結仕様の変更

**推奨は (B) を既定として記録した上で、続けるなら (C) を本丸として検討**。
(A) は Gate 対象群を作れるが、§3 のとおり **primary 候補が 1 本しか残らず、
その 1 本の対照差も ε 未満**なので、(A) だけでは Gate の分解能は戻らない見込み。

いずれの場合も **再測定の前に amendment を単独 commit / pin する**
（`zero_input_false_positive` のときと同じ順序規律）。変更理由は
**「事前登録の操作化がこのレンダ経路で成立しない / 分解能を持たない」**に固定し、
「Gate を通したいから」にしない。
