## 1. 校正結果（19 刺激 × 35 候補）

`spec_version = 1.2-rc1` / `freeze_status = blocked`（全軸通過が凍結条件）

| 軸 | 生存 | 勝者 | 経路床 | `rr_amp_p50` | 分離（要求） |
|---|---|---|---|---|---|
| `excess_tail_voiced_ms` | 1/32 | `S_melshape\|thr0.2\|win100\|hop10` | 70.0 ms | 250.0 ms | **180.0**（≥ 80） |
| `release_after_score_boundary_ms` | 2/32 | `S_melshape\|thr0.2\|win100\|hop5` | 73.9 ms | 253.5 ms | **179.6**（≥ 80） |
| `tail_f0_persistence` | 1/32 | `S_melshape\|thr0.2\|win100\|hop10` | 0.233 | 0.833 | **0.600**（≥ 0.05） |
| `terminal_mel_persistence` | **0/3** | — | 0.086 | 0.056 | **−0.030**（≥ 0.05）**不成立** |

### 1a. 形状軸は振幅に不変だった（(A) の狙いが効いた）

振幅を 40 倍（比 0.016 → 0.628）変えても値がほとんど動かない:

```
excess_tail_voiced_ms   p05 240  p25 240  p50 250  p75 260  p95 260
release_after_boundary  全 rung 253.49（完全に不変）
tail_f0_persistence     p05 0.80 p25 0.80 p50 0.833 p75 0.867 p95 0.867
経路床                  70.0 / 73.9 / 0.233   ← ここだけ明確に低い
```

**相対エネルギーの逆転から抜けた。** 1.1 の τ=0.5 が本番の 84% を無声にしていたのに対し、
形状距離は「まだその母音に見えるか」で判定するので振幅に依らない。

### 1b. mel 軸が落ちた理由 — **過去の報告の訂正**

`terminal_mel_persistence` は「終端窓 mel パワー / ノート核 mel パワー」であり、
**それ自体が相対エネルギー量**である。したがって 1.1 の energy gate を殺した逆転
（床 0.319 > 本番中央値 0.207）をそのまま相続する。3 候補とも分離が負:

| mel 候補 | 床 | `rr_amp_p50` | 分離 |
|---|---|---|---|
| M1_1024_256_80 | 0.0808 | 0.0454 | −0.0353 |
| M2_2048_512_80 | 0.0858 | 0.0555 | −0.0302 |
| M3_1024_128_128 | 0.0856 | 0.0487 | −0.0368 |

**訂正**: 1.0 / 1.1 の記録で「mel 軸だけは本番セルで縮退していない」と繰り返し書いたが、
その非縮退は**振幅のばらつきを測っていた**のであって、経路床と本物の終端を区別する
能力ではなかった。本番代表振幅で問うた途端に破綻する。

## 3. 弱点（引き算して報告する）

- **生存候補が極端に狭い**: 1/32・2/32・1/32。`thr0.2|win100` のみ。単一閾値・単一窓に
  依存した凍結になる
- **`excess` は 300 ms 窓に対し 240–260 ms（80–87%）**で天井側に近い（床 70 ms との差は
  十分あるが、余裕は大きくない）
- **run6/pjs は 3 軸とも床に張り付き**（median 0 / MAD 0）。全群で解けたわけではない
- **ringing が 1.1 より後退**（10/10 → 7/10）

## 4. 停止条件との関係（**裁定が要る**）

裁定の停止条件は 2 分岐だった:

```
1.2 で production_range_resolution が成立 → Gate 1 再判定
1.2 でも飽和・縮退                        → Gate 1 = UNDETERMINED で Run 8 を閉じる
```

実測はどちらにも当たらない:

- **成立した**: voicing 3 軸（本番の縮退も 8/10 → 1–2/10 に解消）
- **成立しない**: mel 軸（分離が負）。全軸通過を凍結条件にしているので spec は blocked
- mel 軸の失敗は **1.2 の設計失敗ではない**。mel 軸は 1.0 から一度も変えていない。
  参照刺激を本番代表振幅にしたことで、**元から持っていた欠陥が露見した**

選択肢は `s7_gate1_verdict.json` 更新前に裁定へ上げる（本記録 §5 = 裁定要請）。

## 5. 言っていないこと

- 「Gate 1 が PASS した」とは**言っていない**。Gate 1 は §6 の耳ラベル（User 作業）が
  無ければ合否が存在しない。1.2 が凍結できても次は耳校正である
- 「1.2 で終端破綻が観測できた」とも**言っていない**。観測できたのは
  **計器が本番セルで動くようになった**ことだけである
- 「ritsu 3 群に破綻が無い」とも**言っていない**。無声基準が取れないのは
  検出器と ritsu の終端の相互作用であって、破綻の有無とは別の話である
