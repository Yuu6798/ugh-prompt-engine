# 収録カード一覧（優先度順: T0 → T3）

**使い方: カードに書いてある文句を、書いてあるやり方で歌うだけ。**
考えることは何もありません。全部録る必要もありません — 上から順に効きます。

- 1 カード = 1 ファイル（20〜60 秒）・順不同・録り直し自由・スマホ録音可・形式不問
- ファイル名の先頭にカード ID（例: `UC-003.m4a`）。間違えても大丈夫（中身で分かります）
- 音の高さは全部「あなたが楽な高さ」で OK。絶対音感的な正確さは一切不要
- メロディ指定のあるカードは、知らなければ適当な節で構いません（歌えていれば何でも良い）

## T1 — 母音のばしカード（2 番目に大事）

**やり方は全カード共通**: その母音を「楽な低さ → 普通の高さ → 楽に出せる高め」の 3 段で、各 5 秒くらいずつ伸ばして歌う（ドー――、と 1 音で保つだけ）。1 カード約 20 秒。

| ID | 伸ばす母音 |
|---|---|
| UC-003 | 「**あ**――」×3 段 |
| UC-004 | 「**い**――」×3 段 |
| UC-005 | 「**う**――」×3 段 |
| UC-006 | 「**え**――」×3 段 |
| UC-007 | 「**お**――」×3 段 |
