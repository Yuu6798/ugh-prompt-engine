## 1. 構成

- **ドナー**: vocadito clip 2（CC BY 4.0・実歌唱・f0 中央値 345.3Hz = さくら score
  +1.01 半音・zip md5 と clip sha256 は本リポ既存 pin `m2c_external_fixtures.yaml` と
  一致 = 来歴クリーン）
- **駆動**: F1a と同一のさくら score 由来 f0 / 振幅（母音核のみ・歌詞なし = ラ歌唱相当）
- **合成**: WORLD（pyworld）。学習ゼロ・torch 不要・完全決定論
- **Genome 変形演算子**: 周波数軸伸縮（formant_scale 相当）・スペクトル傾斜・
  ap 底上げ（breathiness 相当）— テンプレートに対する可読な変形として実装

## 3. 判読（設計判定)

1. **テンプレート路線は計測上成立した**。実歌唱由来の包絡 + score f0 + WORLD で、
   中域をドナーの 74.6% まで回復。手設計包絡（F1a: 声に聴こえない）との対比で、
   humanness の供給源を「手工芸」から「実音声テンプレート」へ移す路線が数値上開通
2. **F1 レンダラの骨格候補が確定**: 「テンプレート銀行（実歌唱 × WORLD 分析）→
   ピッチ索引 + 明るさフロア NN 選択 → Genome 変形演算子 → WORLD 合成」。
   全段決定論・学習ゼロ・グルー約 270 行
3. **診断の教訓**: 3 ラウンドとも犯人は借用部品でなく**自作の駆動側**だった
   （median 設計 / 選択コスト設計）。借りた部品（WORLD・vocadito）は毎回無実。
   F1a から通算すると「壊すのはいつも自分の手作り層」が 4 連続
4. **identity 留意（恒久）**: 単一ドナーのテンプレートは当該実在歌手の音色の
   準クローン。耳判定にドナー本人比較を含め、本採用時は Genome 変形の最低量 +
   複数ドナー混合を §8（Residual Identity Quarantine 同型）ゲートとして必須化する

## 4. 耳判定（2026-08-15・判定者 = User・非盲検）

判定者所見（原文）: 「ドナー本人には聞こえるが自然な声、発声としてはサンプル群は
全て破綻してる。一番ましな nn でも歌にはなってない。ほかのは不自然な破綻があり論外だ」

- 問① 「声」の領域に入ったか → **No（発声として破綻）**
- 問② ドナー本人に聴こえるか → **Yes（identity は転写された）**
- 順位: nn（Round 2・修正前）が最良、nnv2（Round 3）は論外側

### 機序判読（記録者）

1. **計測と耳の逆転を正直に記録する**: Round 3 の明るさフロアは b1k_3k を 0.066→0.286 に
   改善したが、耳では Round 2 より悪化した（ジャンプ率 9.96%→19.03% の時間的非整合が
   帯域改善を上回る劣化として知覚されたと推定）。帯域占有率はエネルギーの**不在**の
   診断には有効だが、自然さの代理指標としては**無効**と実証された。以後、帯域最適化は
   行わない（計器製作は工房立ち上げ後、の方針とも整合）
2. **identity は運ぶが発声が死んでいる**: テクスチャ供給（テンプレート路線）は
   「誰の声か」を運べることが確認された。破綻しているのは (a) フレーム繋ぎが生む
   調音上あり得ない包絡軌跡（テレポートする声道）、(b) score 直結のロボット的
   f0/振幅（定数ホールド + 固定ポルタメント + 位相連続ビブラート = 演奏層の死）。
   実声のテクスチャが載ったことで、演奏層の死がかえって露呈した（本セッション冒頭の
   User 所見「メロディとして成立していない」が、実声音色の対照実験でも再確認された形）
3. **次の測定対象は一意**: 「時間的整合性（連続な包絡軌跡 + 人間的 f0 微細構造）が
   欠けた最後のピースか」を切り分ける対照実験（F1c: ドナーの連続歌唱を保ったまま
   マクロ音高だけをさくら旋律へ差し替える performance transplant）
