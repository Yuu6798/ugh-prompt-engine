# VG-F1a 記録 — 明示 f0 駆動 A/B（レンダラ裁定の交絡除去）

- 日付: 2026-08-15
- 記録者: Claude（Fable 設計判定 + Sonnet 実行委譲、Claude 完結ルート）
- 目的: F0 耳判定（`../results_f0/f0_smoke_record_2026-08-15.md` §7）で両バックエンドの
  負所見に乗っていた交絡 — SawSing = ネットワーク f0 予測、GOLF = speech checkpoint —
  を除去し、「音程が全経路で安定した状態のテクスチャ + 操作性」比較を成立させる
- 生ログ: `f1a_raw.md`。計測: `f1a_bands.json`。グルーコード: `glue_*.py`（4 本、
  そのまま F1 アダプタの種）。共通制御素材（f0/振幅/母音区間）は score から決定論
  再生成可能のため npz は非同梱

## 1. 設計

3 経路すべてに**同一の f0 / 振幅包絡**（さくら score + `performance.py` 由来・
vibrato 5Hz/30cents・24kHz・母音核のみ、子音なし）を与える。音程の交絡を構造的に排除し、
残る差をテクスチャと操作性だけにする。

- A: SawSing DSP コア直駆動（**checkpoint 不使用**。母音フォルマント包絡→倍音振幅、
  ノイズ床 −20dB 固定）— Sins（正弦波加算）/ SawSinSub（のこぎり波減算）
- B: GOLF **ISMIR23 歌声 checkpoint**（MPop600 学習）+ 明示 f0 注入
- C: pyworld 直駆動（同じフォルマント目標の包絡 + 帯域設計した非周期性）

## 3. 判読（設計判定）

1. **v5 の「4–8kHz 実質ゼロ」は A / C で解消した**。明示的な高域ノイズ注入
   （A: 白色床、C: WORLD 非周期帯域設計）で、v5 レンダラに構造的に存在しなかった帯域が
   出せることを実証。A の HNR 低下（1.6–2.8dB）はノイズ床を粗く −20dB 固定にした
   調整不足であり、アーキテクチャの限界ではない（帯域整形・レベルは自由に運転できる）
2. **GOLF に構造的な負所見**。明示 f0 注入は成功した（ピッチ軌跡の差し替え自体は可能）が、
   スペクトル包絡は encoder が**入力音声から**予測するパラメータに支配され、外部からの
   f0 差し替えでは変化しない。つまり GOLF は analysis-by-synthesis の**コーデック**であり、
   「Genome から手で運転する楽器」（設計原則 P2）として使うには decoder の学習 latent を
   直接駆動する研究級の改造が要る。加えて ISMIR23 checkpoint と現行コードの間に
   cross-version 回帰（config キー拒否・`Mel2Control` の f0 kwarg 不在）があり、
   CLI 経路は 1–5 行パッチ予算では開通しなかった
3. **操作性の序列が確定**: A（物理的意味のある制御 = f0/倍音振幅/ノイズで直駆動・
   checkpoint 不要・107 行）≈ C（全パラメータ明示・98 行）≫ B（自前ドライバ 124 行を
   書いてなお音色は入力拘束）。工房の要件は「良い音」ではなく「Genome から運転できる音」
   であり、この軸で B は脱落に近い
4. 副次所見: A / C とも学習フリーで走った。F1 レンダラは当面**学習なしで組める**見込みで、
   neural residual は設計書 v0.2 の R3（RQ ゲート付き）として後段に温存できる

## 5. 耳判定（2026-08-15・判定者 = User・非盲検）

判定者所見（原文）:
- pyworld: 「最下位」
- SawSing コア直駆動（Sins / SawSinSub）: 「強いノイズが発生する副作用アリ。
  音程は取れてるがこれを採用しづらい」
- GOLF 系: 「サンプルのなかでは一番安定。glottal がやや良い」

### 機序判読（記録者）— この順位が実際に測ったもの

**A / C は同一の自作包絡（ローレンツ型母音目標 + 白色ノイズ床）で駆動され、
B だけが学習済み encoder の包絡で鳴っている。** つまりこの耳判定はコアの比較ではなく
**スペクトル包絡の生成品質の比較**になっていた（F0 の f0 予測交絡・speech ckpt 交絡に
続く第 3 の交絡。正直に記録する）。

- pyworld 最下位 = 自作包絡の帯域バランス（b1k_3k 0.48 / b0_500 0.11 は人間の声に
  存在しない配分）がそのまま聴こえた。WORLD 合成そのものの敗北とは言えない
- SawSing のノイズ = 記録者が粗く置いた −20dB 白色床（HNR 1.6–2.8dB）。これも
  駆動側の欠陥
- GOLF の安定 = encoder が実音声入力から予測した「本物らしい」包絡の勝利

### 帰結（重要）

**品質の律速はコア選択ではなく、包絡/テクスチャ生成層にある。** 手設計ローレンツ包絡
（= R0.9 と同じ手工芸路線を 100 行に縮めたもの）は声に聴こえず、学習由来/実音声由来の
包絡は声に聴こえる。ただし GOLF の勝ちは fork 復活を意味しない — GOLF の包絡は
**入力音声から**しか得られず、無からの創生（工房の使用形態）には入力音声が存在しない。
必要なのは「入力音声なしで人間らしい包絡を供給する機構」であり、次スパイク F1b で
テンプレート路線（実歌唱からの包絡抽出 + Genome 変形）を検証する。
