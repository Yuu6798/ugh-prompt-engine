【RUN9 User裁定 — execution_profile_sha】

RUN9 の実測 smoke profile として以下を承認する。

runtime:
  python: "3.11.15"
  os: "Ubuntu 24.04.4"
  architecture: "x86_64"
  onnxruntime: "1.29.0"
  selected_execution_provider: "CPUExecutionProvider"

この実測環境を RUN9 の基準 execution profile とし、
機械可読な execution_profile manifest として保存し、
その raw byte sha256 を RUN9_CONTRACT.yaml の
execution_profile_sha に PINNED することを承認する。

重要:
- selected_execution_provider は CPUExecutionProvider に固定する。
- available provider の列挙と、実際に session が選択した provider を混同しない。
- GPU/CUDA provider への自動fallback / upgradeは禁止する。
- provider または主要runtime versionが変わる場合は、
  同じ execution_profile_sha を使わず再pinする。

smoke benchmark:
  observed_seconds_per_item: 24.1
  planned_item_count: 616
  estimated_total_runtime_hours: approximately 4.12

benchmark値は実行能力・費用・所要時間の参考記録であり、
出力同一性を定義する execution profile の意味論そのものには含めない。
マシン負荷等により速度が変わっても、それだけで再現性違反とはしない。

可能であれば execution profile manifest には追加で以下を実測記録する:
- CPU model
- logical CPU count
- onnxruntime available_providers
- onnxruntime selected providers
- intra_op_num_threads / inter_op_num_threads
  （未指定なら DEFAULT と明記）
- numpy version
- soundfile version
- render code commit
- deterministic seed / thread environment variables

これらは推測で補完せず、実測できた値のみ記録する。
