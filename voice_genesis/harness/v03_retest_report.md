## 1. 総合判定

**改修の主目的 —「判定不能だったゲート体系を、判定可能で原因分離のできる
計器に直す」— は達成された。** 一方、全項目が緑になったわけではなく、
新しい計器が**本物の問題を 3 件検出した**。これはゲートが機能し始めた証拠
（v0.2 の体系では原理的に検出も判定もできなかった）であり、fail-closed
原則に従い次サイクルの改修対象として申し送る。

| ゲート | v0.2 時点 | v0.3 再テスト |
|---|---|---|
| VT-1 plausibility 不変条件 | 検査自体が存在せず（縮退が素通り） | **PASS**（122/122 違反 0。検出構造も確立） |
| VT-2 Phase 0（数値凍結後） | 数値未束縛で判定不能 | **FAIL** — ただしゲートが R0.1 の新規回帰を正しく捕捉（下記 3） |
| VT-3 grip（4 軸） | 定義欠陥で全軸 FAIL（判定に意味なし） | **1/4 軸 PASS**、残 3 軸は原因が特定・分離された FAIL |

## 2. grip v2 の結果と原因分離（v0.2 → 構成(1) 定義改修のみ → 構成(2) 定義+レンダラ改修）

| 軸 | v0.2 (z-score) | (1) 定義改修 | (2) +R0.1 | 判定と原因 |
|---|---|---|---|---|
| vibrato_depth | 0.682 | 4.284 | **9.215** | **PASS（両構成）**。v0.2 の FAIL は定義欠陥 + 計器外れ値が原因だったと確定 |
| breathiness | 1.025 | 0.845 | 2.358 | FAIL だが R0.1 の tilt 整合ノイズで +1.5pt。entanglement 実測も +65.3%→−7.3% に改善。残り 0.6 はレンダラ側の継続課題 |
| formant_scale | 0.571 | 1.699 | 1.825 | FAIL。定義改修で 3 倍化（v0.2 の過小評価を確認）。残る主副作用は tilt との共線性 |
| spectral_tilt | 0.819 | 0.729 | 0.638 | FAIL。支配副作用が一貫して centroid — **特徴量セットの構造的共線性**（tilt を動かせば重心も定義上動く）。定義・計器・レンダラのいずれの改修でも解消しない第 3 の原因と特定 |

- 全 8 セルで `below_instrument_resolution` なし（意図効果はすべて 3σ_meas 超）
  — 計器分解能開示の運用が成立。
- E(intended) ≥ 2.0 の新条件は全軸クリア（「効かないツマミの偽合格」防止条項は
  発動せず、健全に機能）。

## 3. VT-2 v2 — ゲートが初仕事をした（R0.1 の高音域回帰を捕捉）

- カナリア（レンダラ非経由の純音 4 点）: PASS — ハーネス自体の健全性を毎回
  機械照合する仕組みが成立。
- コア帯域 C2–C7: median 8.55 cents（≤20c 条件は満足）だが、**MIDI 93 / 96
  （B6/C7 付近）で −505.8c / −1203.6c の新規大誤差**により FAIL。
- 診断で原因を単離済み: 同一 Genome・同一計器でレンダラのみ v0↔R0.1 を
  切替比較 → v0 は両ノート 50c 以内、R0.1 のみ破綻。fmax スイープ
  （2200–3200 Hz）は無関係。**§C-1 のノイズ tilt 整合が高音域の周期構造を
  変え、推定器の境界近傍弱点を再露出させた**レンダラ起因の回帰。
- VT-3 の caveat セル数（外れ値棄却率 >5%）も R0.1 で一貫増
  （3→6 / 1→3 / 0→4 / 2→6）— 同一回帰と整合。
- **含意**: v0.2 の未束縛ゲートならこの回帰は「改修 = 改善」として素通り
  していた。数値凍結 + カナリア + レンダラ切替診断が、まさに設計書 §P6
  （Stage-gated development）の意図どおりに働いた。fail-closed に従い、
  **R0.1 は高音域回帰を解消するまで R0 を置換しない**。

## 4. 次サイクルへの申し送り（優先順）

1. **特徴量セットの直交化**: tilt↔centroid の共線性解消（例: tilt を
   「フォルマント包絡補正後の残差勾配」として測る / centroid を
   「tilt 回帰残差の重心」に置換）。formant_scale / spectral_tilt 両軸の
   gate 到達はこれが律速。
2. **R0.1 高音域回帰の修正**: ノイズ tilt 整合を帯域依存にする
   （高音域では整形を弱める）か、推定器側の短周期整合を強化。修正後に
   VT-2 v2 を再実行し全数 ≤100c を回復すること。
3. **breathiness 残り 0.6**: ノイズの centroid 中立性はほぼ達成済み
   （−7.3%）。次は tilt 側への漏れ（構成(2) の残存副作用）の低減。
4. 設計文書 v0.3 への反映: 本メモ §A（JND 表 + 3 条件 gate + 分解能開示）を
   §7.2 の正文として転記、§E の凍結数値を §9 Phase 0 に転記、
   underspec_log v1/v2 の計 25 件を仕様値として本文に取り込む。
