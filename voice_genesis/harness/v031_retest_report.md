## 3. Phase 0 ゲートの完全通過（推定器強化の詳細）

- R0.1: MIDI 93/96 の −505.8c / −1203.6c → **14.6c / −9.3c**。コア帯域
  全数 max 41.5c、median 8.55c。
- v0（非退行）: 全数 max 56.2c、median 8.68c。カナリア全点 ≤14.1c。
- 実装過程で**素朴な櫛照合自体が 2 つの新規回帰を起こし、実測で対策された**
  （underspec_log_v3.md に完全な記録）:
  1. マージンなし argmax → 低音域で missing-fundamental の逆流
     （エネルギー比 1.5 を上書き閾値に設定して分離）
  2. フレーム単位判定 → ノート内不安定（ノート単位判定へ）
  3. 単純中央値 → bimodal 分布の「隙間」を返す欠陥（最大クラスタ中央値 +
     アンカーから 300c 超のフレームを NaN 化する頑健化）
- 副産物の発見: MIDI 93 で **1/3 分周クラスタ**（{l, 2l, l/2} 候補集合の
  対象外）が観測された。現行ゲートは代表値の頑健化で守られているが、
  候補集合への 3l/l·3 追加は将来の強化候補。

## 4. 残課題と設計含意（次サイクルの入力）

1. **共線性は消えず「一段深く」移動した**: 旧 centroid↔tilt は解消したが、
   後継の formant_centroid↔source_tilt が新たな相互副作用源になった。
   機序も特定済み: (i) formant_scale を動かすと F1_est が動き、source_tilt の
   回帰対象倍音集合（k < 0.9×F1/f0）自体が変わる。(ii) tilt を動かすと
   ケプストラム包絡のピーク位置がわずかに動く。**音響のみからの逐次推定では
   source と tract の完全直交測定に構造的下限がある**可能性が高い。
2. 次サイクルの設計選択肢（Fable 判定は次回冒頭で確定):
   - **案 A — 同時推定**: source-filter モデルの joint fit（tilt と formant を
     同時最適化するデコンボリューション）で逐次推定の連鎖依存を断つ。
   - **案 B — ゲート意味論の改訂**: v0.2 設計書自身が §7.2 で警告していた
     「声帯物理由来の絡みによる偽 entanglement」が測定レベルで再出現したと
     解釈し、**宣言済み既知結合の免除表**（axis ペアごとに予期される符号・
     量を宣言し、grip は未宣言の副作用のみを数える）を gate 仕様に導入する。
   - 両案は排他でなく、A で下げられるだけ下げ、残余を B で宣言する複合が
     本命候補。
3. 軽微な注視事項: breathiness 軸の支配副作用が mean_f0 に移った
   （E は閾値未満で実害なし。追い込み時に注視）。
