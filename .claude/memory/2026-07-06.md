## Design Decisions

- **#151 = 11 軸 variant sweep + 事前登録採択規則**: 一般化した校正ハーネス
  （`--axes-config`・相関行列/符号センサス/ジャンル効果量で軸ハードコード除去）で
  現行 5 軸+variant 3+新 3 軸を 1 回の sweep で実測し、実行前に登録した規則で機械裁定。
  brightness=B2 採用（counter-stereotype テンポ中和 probe。bpm 干渉 d=+2.37→+0.52 で
  自ノブ d=+1.38 が初めて干渉を上回る。B1=語彙除去だけでも 0.55 まで落ちる＝交絡主因は
  probe 語彙）/ warmth=W1 採用（analog/digital 質感へ再照準、r(brightness) −0.827→−0.22
  で撤去回避）/ electronic_production 新設（**真値付きジャンル軸第一号**: StartinA
  EDM×Rock matched-pair で効果 7.0×>再生成ノイズ）/ valence 新設（探索。プールでは
  r(brightness)≈0.80＝単独読み不可を明記、本来の検証場は #147 セクション別感情アーク）/
  **tension 不採用**（energy と r=0.969 重複 — warmth を r=0.83 で手術した規律と同一基準の
  負の結果記録）。v1.0 brightness の「ジャンル分離力」(10.1×) は B2 で 0.94× に消失＝
  テンポ・制作様式の交絡だった可能性が高く、ジャンル読みは electronic_production に分離。
- **#152 = K2-seg（compose プロンプト欄 grip スクリーン）**: 検証原則は「compose が
  実際に出す文言 verbatim の A/B」（もっと効く文言探しではない）。MusicGen small
  pin 済みで 5 ノブ×2×R=8=80 クリップ・人手ゼロ。判読: semantic.core 文言は**効く**
  （物理 onset_density d=−0.70 は盲だが CLAP energy d=+1.90 = 物理 dead×意味層センサー
  生存の「センサー盲」診断実例・v1.1 バッテリー初実地成果。valence も d=+0.60 方向正）/
  **本文 "Avoid: X" は X の attractor**（centroid d=+1.10 で逆方向・否定語無視）/
  active_rate loose 0.39（天井: low セル既に 0.967）/ valley_depth dead（素材床と分離
  不能）/ 3/4 拍子指定 0/8 不達（抽出器 4/4 バイアス併記）。スコープ外を構造的理由で
  宣言: stereo（mono 出力=sensor_blind 既証）・structure セクション（12s に曲構造は
  現れない=Suno 人手課題）。dead/loose の profile 追記が musicgen compile の drop 順を
  変えるのは PR1.5 の本来機能として意図的に許容（テスト pin）。semantic_core の loose
  判定は SEM-1 昇格ゲート踏襲（CLAP d=1.90 は tight 域だが学習センサー由来は loose 固定
  honesty）。
- **#153 = 実測なき横展開をしない**: 本文 Avoid 送出停止は **musicgen のみ**
  （descriptor 宣言 `omit_body_negative`）。Suno は Exclude Styles と重複でも実測が
  ないため不変（K3-2a 機種間符号反転の教訓）— Suno 本文 Avoid 検証は人手キュー化。
  negative_tags は保持（楽譜の意図保全・消費可否は下流責務）、「字数超過 drop」と
  区別して dropped_elements に入れない。
- **Codex P2 通算 3 件・全 1 ラウンド解決**: #151 ゼロ分散ペア null 化 / #152
  「Avoid advisory が実は発火しない」（ドット名解決不能×applies_* 必須の二重原因 →
  制約なし×advisory 非 null は非空時発火の最小一般化）。後者は headline finding の
  警告が肝心の時に沈黙する本物の配線漏れで、bot 指摘の価値が高かった。
