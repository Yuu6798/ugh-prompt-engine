### Design Decisions
- **製品の重心の再確認**: 一時「promptability 計測ツール」と言いかけたが、ユーザーが
  「楽譜という基本コンセプトはブレない」と是正。prompt は `compose` の射影であり、
  検証対象は一貫して **楽譜が演奏を支配/再現できるか**。この読み替えを doc にも反映。
- **双方向性テストの成功スコープを厳密化**: Codex の連続指摘により、「物理層が再現」
  という当初主張を **実際に Suno へ送出した数値ノブ（key / brightness）のみ検証済み**
  へ段階的に絞り込み。bpm は 89.1 アトラクタと交絡し判定不能、time_signature は
  renderer に segment 無しで完全未送出、active/valley/stereo は数値ノブ未送出だが
  構造プロンプトに質的キューは届く、と区別。
- **計測値は記録値（再測不可）**: 音源未コミットのため、本 doc の数値は観測ログで
  あり校正データではない。Q1-3/K2 が再利用するには音源+manifest の保存が前段で要る。
