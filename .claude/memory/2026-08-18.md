### Design Decisions

- **spk_id map v2 の実装形**: `assemble_run4.py` は v1/v2 切替なしの全面
  移行（設計 §2-1 どおり）。D2/D3 マージサブシステム（CSV 行連結・ヘッダ
  接頭辞検査・衝突検査・専用例外 2 種）を撤去し 4 話者同型バイトコピーへ。
  manifest schema 0.4（collision_check・ritsu の components/d2_*/d3_* 撤去）
- **無人ブートストラップの停止保証**: main 全体を try/finally 化し
  self-stop をどの経路でも保証・例外は Exception で受け traceback ごと
  heartbeat 退避・salvage は失敗地点非依存のディスク実態収集 + 致命側
  rclone push（失敗を exit code に表面化）。NaN スキャンは「サイズ安定待ち
  + 読めない(exit 2)/NaN(exit 1) の区別 + 再試行上限」で偽 NaN kill を排除
- **素材 pin の来歴書き分け**（User 指示）: ffmpeg BtbN n6.1.2 = 「強」
  （当方実測起源・実体再検証済み）/ vocoder pc_nsf_hifigan = 「中」
  （クロー報告値・run 4 40K 完走の間接実証のみ）。転記時に両方 URL から
  独立 DL し全 sha256（tarball/bin/zip/model.ckpt）一致を再実測。
  **DESIGN_S4 §3.2 の「nsf_hifigan.onnx」は起草時の誤記と判明**（run 4
  実績は pc_nsf_hifigan zip+ckpt。学習側 vocoder とローカル ONNX vocoder の
  2 系統は別物 — DESIGN へ注記済み・pins 表が正）
- **一次ソース照合の収穫 2 件**（Sonnet 委譲）: (1) DiffSinger e2307b1
  binarizer は `{ds_id}:{item_name}` 複合キー + 整数連番 HDF5 格納 =
  話者跨ぎ同名は無衝突（マージ撤去の安全性を下流まで接地）。副産物:
  configs/acoustic.yaml:15 の既定 vocoder_ckpt が pin 配置先と逐語一致。
  (2) 波音リツ zip は UTF-8 フラグ無し cp932 格納 — zipfile 素展開の
  cp437 化けを実 zip で実測 → metadata_encoding='cp932' 採用
