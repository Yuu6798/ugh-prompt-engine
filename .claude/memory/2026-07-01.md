### Design Decisions
- **アレンジ = identity(key+chord進行) 固定 × ジャンル/テンポ/dynamics 再キャスト**。
  「変えたら別曲になる所」と「変えていい所」を機械的に分離。
- **BPM は原曲に matched（統制変数）**。halving（デフォルト抽出が高速曲を÷2/3:2に折る）
  は高 prior で真値回復。実音源(TOUGH BOY 86→172, Song2 78→152)でも再現＝**抽出器の
  普遍的癖であり生成器の問題でない**と確定。
- **fixity は「編曲意図」でなく「値の有無(locked=具体値/unlocked=TODO)」記述用**と判明
  （検証エラーで学習）。アレンジ意図は散文で記録。
- **n=1 の過剰一般化を n=2 で棄却する honesty を貫徹**: 「ボーカル=主音の錨」は
  TOUGH BOY(歌あり→C#正/歌なし→G#属音)で綺麗に見えたが、Song2 で方向反転
  (歌あり→D#属音/歌なし→G#正)→法則でなく交絡の存在のみが実在。halving も
  ボーカル法則でなく非法則化。**法則化は n≥3 まで保留**。
- **核心=歌詞は意味層のアンカー**: 歌詞が付与する「メリハリ(曲らしさ)」は物理
  dynamic_range に写らない（むしろ逆相関: 歌あり 7.54<歌なし 8.99）。中域 mid_ratio は
  ボーカル検出に堅い(2/2)。→ **物理計器の盲点＝意味層、現状は耳が唯一のセンサー**。
- docs 単独 PR（Claude の担当領域）。索引を README+CLAUDE.md の 2 箇所同期。

## Session Summary — 2026-07-01 (Session 2)

### Context
「実音源を使ったデモ」の第2弾。ユーザー提供の実音源 `StartinA_COMPLETE`(m4a) を
identity(調号/コア進行)固定で **EDM / Rock** の2アレンジへ再キャストする Suno プロンプトを
生成し、各アレンジ「歌詞あり/なし」＋**歌詞側の再生成別取り(alt)** の実 Suno 出力を
`svprpe extract`/`transcribe` で計測。前セッション(#123)の「歌詞→dynamic_range 低下」を
n=3 で検証した。歌詞は Claude が意味層として作詞し `[instrumental]` と出し分け。
成果を `docs/lyrics_semantic_anchor.md` の n=3 追試節＋計測ログに保全し **PR #124 マージ完走**。

### Design Decisions
- **アレンジ = identity(調号/コア進行)固定 × ジャンル/音色/構造 再キャスト**。BPM は
  原曲 108 に matched(統制変数)。EDM は Suno の四つ打ち prior に負け 129 へ精密ロック、
  Rock は 108±5 で揺れ＝**grip は「確度×精度」の2軸**（当たるか×揃うか）。
- **dynamic_range=歌詞アンカー説は棄却(n=3)**。Rock で歌詞あり/なしが反転、しかも
  再生成ノイズ未満。EDM は方向は残るが instrumental alt 未取得で directional 保留。
  前セッションの「n≥3 まで保留」判断が正しかった。
- **mid_ratio は最有力ボーカルセンサーだが noise 超えは Rock のみ**。EDM は条件差
  (0.004)<スプレッド(0.005)で directional のみ。昇格は各ジャンル instrumental alt 込みの
  **n≥2×2 セル要件**。→ **「効果 > 再生成ノイズ」基準を全指標に一様適用**する規律を確立。
- **key(調号)は grip・進行は grip しない**: 生成6中5が ♯4(E major / C# minor)ファミリー
  保存(転調なし)、失敗は rock_inst 1本(歪みギターのクロマ推定ノイズ疑い・n=1 断定せず)。
  トニック重心/進行はテイク毎に書き換え(推定器律速で断定不能)。
- **歌詞あり/なしは Suno 出力の byte_size で弁別**(大=歌詞あり)。計測ログは原ファイルの
  `audio_sha256` を pin し変換レシピ(ffmpeg 44100/stereo→extract)を明記=再現可能化。
