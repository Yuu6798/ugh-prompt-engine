## Design Decisions

- **#142 key 一致判定の統一 = consolidate であって collapse でない**: 実測で key
  比較は **5 コピー・2 系統**（`compare.keys_match` の異名同音 boolean / `audit`・
  `measure_grip`・`build_k3_fixture`・`build_k3_musicgen_fixture` の mir_eval 加重）。
  boolean 系（往復の二値 verdict）と weighted 系（近縁調の段階効果量）は**意図的に
  別概念で統合してはならない**（＝負債メモの「挙動変更」リスクの正体）。真の重複は
  weighted 系 4 コピーで、唯一の差「fallback / fail-fast」を `require_mir_eval` 引数で
  吸収し `svp_rpe/keys.py` へ集約。挙動完全保存。循環 import は `perform` の関数内
  遅延 import で回避。
- **#143 CLAP 埋め込みサイドカー化 = ロスレス退避**: 巨大な `audio_embedding`
  （32×512 float=326KB の主因）は**消費側精査でアーカイブ provenance 専用**と確定
  （実計算は保存済み cosines/contrast_fit を使い、唯一のテストは非空チェックのみ）。
  → `<stem>.embeddings.json` サイドカー（text JSON・diffable/sha ethos 準拠、binary
  npz は不採用）へ既存値のまま退避（CLAP 再実行なし・数値再生成なし）。schema 1.0→
  1.1。`split_fixture`/`merge_fixture` は round-trip 恒等。Codex P2=重複 `sample_id`
  fail-fast。
- **#144 CI nightly extra = install-only（案 A）**: 実際の回帰（#138 CLAP / #139
  basic_pitch・panns・beat_this ×3）は全て「extra を入れると本物パッケージの

  だが独立ジョブで scoped に赤=可視シグナル）で決着。

## Design Decisions

- **本筋 = CLAP を「事後比較器」から「抽出段階センサー」へ**: `contrast_fit` は
  既に汎用 A/B 器で、軸（positive/negative テキスト集合）を差し替えれば任意の意味軸を
  読める。現状 vocal/bright の 2 軸のみ fixture 化されていた → 意味軸バッテリーを config
  化し、抽出段階で SOURCE 音声を読む sensor を新設。
- **isolation 厳守（全 3 PR 共通）**: 学習出力は `LearnedAudioAnnotations` にのみ格納し
  `SemanticRPE`/`PhysicalRPE`/`SVPForGeneration.style_tags` へ write-through しない
  （learned_models_policy §2）。`contrast_fit` は符号付き学習版 grip で `[0,1]`
  confidence でも verdict でもない。各 PR の isolation テスト（SVP 出力同一・sentinel
  非リーク）で pin。
- **#146 は DD-D 尊重が肝**: `transcribe` の意味層フィールドは「人間が書く欄」
  （score_centric §5 DD-D）。CLAP 読みは **auto-fill せず YAML コメントブロックの
  advisory** として draft 先頭に添える（「計器＝作曲前のパラメータ取得道具」の役割）。
  全行コメントゆえ draft は loader-valid のまま。意味層 TODO 保持をテストで pin。
- **#147 は superset 設計**: `--clap-sections` は whole-track（#145）+ 区間別を両方
  populate。`embed_audio_file` のコアを `_embed_waveform_vector` へ抽出し**挙動保存
  リファクタ**（`test_clap_adapter` 33/33 unchanged で証明）、`embed_audio_segments` で
  1回デコード→区間スライス→決定論。fake の L2 正規化後 scale-invariance を honest に扱い、
  「区間差→ベクトル差」の property のみ length-aware fake で検証。
- **schema バージョン規律**: `LearnedAudioAnnotations` に `semantic_axes` 追加で 1.0→1.1
  bump（#145）、その後 `semantic_axis_sections` 追加（#147）は default 空リストで
  同版互換のため 1.1 維持。
- **fail-fast プローブ（#146/#147 が #145 の Codex P2 を踏襲）**: `ensure_clap_available()`
  （import プローブ・重み DL なし）を基底抽出の前に呼び、extra 未導入時に抽出時間を
  浪費せず exit 1。install ヒントは `markup=False` で `.[semantic-embed]` を Rich markup
  から保護。
