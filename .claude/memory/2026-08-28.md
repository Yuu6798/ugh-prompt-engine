### Design Decisions

**R10-PUB-1（公開境界）**: 本リポジトリが public であることに気づいた時点で
黙って進めず §33 の User 裁定に上げた。裁定 = `APPROVED_CODE_ONLY_PUBLIC`
（実装コードのみ public）。後日 User 再確認「UTAU デフォルト音源は個人非公開
でのみ分析や抽出、合成を許されてる。リポジトリに乗せるのはダメだ」を受け、
同じ保守的姿勢を VG 側の Evolution Theory v0.3 本体にも適用した。

**A0 は生成できない**（User 質問への回答）。合成すれば比較が VG 対 VG になり、
それは §12.3 / H10 / Outcome C がまさに検出対象とする measurement overfit
そのもの。§7.1 の provenance pin と §32 Stop Rule 3 により合成代替は不可。

**Gate を捏造しない**。R10-G0 / G1 / G2 はいずれも BLOCKED のまま。PASS を
作れる材料（A0 実体・AF01 bundle・設計文書実体・cost cap 裁定）が無いことを
3 値（PRESENT / ABSENT / UNRESOLVED）で正直に記録する方式に統一した。

**bot レビューの終端方針**。Codex 24 巡（#330）+ 2 巡（#332）で、同型の欠陥が
繰り返し出た。個別修正をやめてファミリー単位で終端する判断を 2 回行った:

1. **「開いたキー集合」ファミリー**（第 12/13/15/17/19/20 巡＝6 度再発）→
   検証で降りる mapping を `SHAPE`（キーが設計の固定語彙 → 未知キー拒否）と
   `INDEX`（キーが trait id 等のデータ識別子 → 閉じられない。行を SHAPE として
   閉じる）に分類し `MAPPING_CLOSURE_INVENTORY` へ全数登録。**閉世界化の正しい
   形は「全部閉じる」ではなく「種別を宣言し SHAPE だけ閉じる」**（INDEX を
   閉じると測定結果が記録できなくなる）。
2. **「宣言されたが適用されていない検証器」ファミリー**（第 4/22/23 巡）→
   `tests/test_enforcement_wiring.py` で ast 静的解析（走査範囲は非テスト .py
   全数発見・到達可能性は公開関数起点の呼び出しグラフ）。例外は理由付き登録制。

**#332 第 2 巡で収束しないと判定**。3 件とも監査の解析精度への指摘で、完全な
呼び出しグラフ解析器を作る方向ではなく **主張を実態まで狭める**方を採った
（指摘自身が代替として挙げた選択肢）。`AUDIT_LIMITATIONS` に再入条件付きで
3 件の限界を宣言。**PR #330 第 23 巡の欠陥（private 述語の分岐単位の適用漏れ）
は本監査の範囲外**であることを明記した — 動機に挙げながら捕捉できない、という
指摘は正しい。

**pin の出所を 1 箇所に**（第 18 巡）。Evolution Theory の digest をモジュール
定数と契約 YAML の 2 箇所に持つ設計だったため、乖離すると R10-G0 が片方を検証
しながら R10-G2 が別バイトを PRESENT と書ける。定数を廃止し契約を唯一の出所に
した。**乖離の「検出」ではなく乖離し得る状態そのものを無くす**方向で終端。
