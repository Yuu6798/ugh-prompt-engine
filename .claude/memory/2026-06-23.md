  `perform/`/`roundtrip/` を src 外に描き、`compose/`/`control/`/`rpe/learned/`/config 群を
  欠落）を実態同期。docs 22 本を Sonnet サブエージェント 3 並列で対実装監査し、ドリフト
  13 件を修正。**高インパクト主張（UGHerScore フィールド名・cli.md の compose/audit 欠落・
  roadmap_goal2 R0 実装済み等）は鵜呑みにせず自分で grep 裏取り**してから修正。
  roadmap 系のフェーズ完了マークは「状態マークは慎重に」方針で **❌未着手→⏳実装済み
  （受け入れ/運用は別）** に統一し "完了" 断定を回避（凡例 ⏳ の定義に合わせた）。
- **test 高速化（#96）**: フル 602 tests/約6.5分の重さを調査。原因は「モック不使用方針で
  ほぼ全件が音声合成+librosa 実抽出の CPU バウンド」。**xdist 並列は不採用と実測判定**:
  (1) librosa/numpy/scipy が既に native スレッドで全コア使用 → プロセス並列は
  オーバーサブスクライブのみで `-n 2` が 392s＝直列と同等、(2) 並列下で librosa の
  numba JIT ディスクキャッシュ（共有 `__pycache__/*.nbc`）が並行書き込みで破損し
  **直列実行まで segfault** に巻き込まれた（キャッシュ削除で回復確認）。代わりに `slow`
  マーカーで日常ループを 6.5分→約3.4分に。
