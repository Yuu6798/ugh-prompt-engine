### Design Decisions

- **S1 学習事故の系譜と最終構成**: run1=fp16 AMP で 5K-10K 間に全 NaN / run2=bf16+clip
  でも step 5300→5400 で突発 NaN / run3=**5K から finetune 機構（optimizer 新品）+ LR 0.0002**
  で 40K 完走（NaN ゼロ・val_loss 0.165・総費用 3 run で $5 弱）。教訓=各 5K 節目の NaN
  スキャン規律。
- **S1 ゲート「土俵に乗る」の具体化**: 5 判定ポイント（①歌声か ②日本語か ③接合ノイズ
  不在の維持 ④S0 との差が量的か ⑤2 話者の描き分け）を User が全クリア判定 → S1 通過。
  **F1.x の構造病だった接合ノイズが自前学習 5K 地点から不在** = 方式転換の核心仮説を実証。
- **S2 ブラインド判定規律**: 対応表 sha256 封印→判定後開封・バッチ 4 候補分割（User 指示）・
  隠しコントロール（バッチ 2 以降）・判定反転の正直会計（バッチ 1 の原判定+開示後修正を
  両方保持）。科学的成果: **「第三の声」仮説 β 陽性 2 例**（H=直交摂動・J=lerp0.65+摂動）/
  り→ん破綻はリツ成分残存量の単一要因 / 電子音ノイズは NSF-HiFiGAN vocoder 由来 /
  耳と mel 距離の乖離=評価器ブートストラップ問題の実測第 1 号。「誰でもない×破綻なし」
  同時達成 0/10 → **backfill 処方箋 = D3（F1.4 レンダのリツ歌唱合成データ）+ BigVGAN v2
  44kHz（MIT・商用開通）** を確定。
- **第 3 ドナー = User 本人**: license-clean 追加候補が実質 User の声のみと判明（コシラズは
  ONNX 配布で再学習権なし）→ 積み立て型収録キット（20 カード・「書いてある文句を書いて
  あるやり方で歌うだけ」形式）で解決。**音域は既存 2 ドナーより約 1 オクターブ低い**
  （実測 B♭2〜G♯3）= 補間空間が線分→大きく開いた三角形になる理想配置。
- **Codex レビューの実害基準カットオフ**（R25 前後で確立・AGENTS.md §3 の運用深化）:
  毎ラウンド全採用を続けると変種が無限生成されるため、①新実害クラス ②自前修正の欠陥、
  のみ採用し同型変種は境界宣言で見送る前方宣言を R26 で掲示。R27–R30 は全て「自前修正の
  欠陥」枠で採用、R31（並行 export レース）で見送り第 1 号を適用。**同型穴ファミリー終端
  8 系列**を宣言: 単一 read 束縛 / 自己ハッシュ（無限後退の不動点論証） / truthy ガード /
  決定論 tmp パス / 開封会計 / 台帳検証 4 階層（schema→リスト→型→値不変条件） /
  exporter provenance / rename・move→記帳窓（ファイルシステム状態導出へ統一）。
- **回帰規律の徹底**: gate_synth に触れる全コミットで canon 回帰 5 本（reflow 4 WAV +
  canon DDPM `42f459d5…`）の sha256 実測 byte-identity、convert_pjs/build_dataset に
  触れる全コミットで実 PJS 100 曲 worktree 比較を必須化。サブエージェントが「資産なし」
  と誤認して実測を省略する事象が 2 回発生（R21/R28）→ いずれも資産所在を示して差し戻し、
  実測完遂まで完了扱いにしない運用で対処。
