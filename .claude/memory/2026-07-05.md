## Design Decisions

- **環境の壁の真因特定（記録訂正）**: 「semantic-embed は proxy env でビルド不能」
  （07-03 S3 記録）の真因は proxy ではなく **Debian patched setuptools の
  `install_layout` AttributeError**（laion-clap の legacy sdist 依存 wget/progressbar
  のビルドで発火）。`pip install -U setuptools` で解消し、当リモート env でも
  torch+CLAP+重み 2GB が導入可能と実証。docs/semantic_sensor_clap.md に補足済み。
- **#148 校正は embedding 空間方式**: 音源を持たずに、#143 サイドカーの**保存済み
  実音源埋め込み**（実 Suno 6 + 実 MusicGen 32）へ battery probe テキストだけを
  埋め込んで照合。fixture の checkpoint sha256 ピンと同一チェックポイント
  （music_audioset / HTSAT-base）をロードすることで空間一致を保証 — この前提自体を
  Codex P2 3 連で計器ゲート化（①ピン照合 fail-fast ②ゼロノイズ床でも
  |effect|>noise ゲート保存 ③run 内非決定/再現乖離>1e-5 で書き出し拒否）。
- **#148 軸別判定**: vocal_presence=実証済み（15.7×/11.4×、#131 再現・マシン間
  乖離≤1e-6）/ energy=実証済み・最良選択性（bpm d=+2.57 vs brightness d=+0.18）/
  brightness=方向正だが **bpm 干渉 d=+2.37 が自ノブ d=+1.52 より強い**（K3-2b と
  整合・併読必須）/ acousticness=探索（電子プールで負符号 19/38＝絶対符号は
  verdict 不可の実測裏付け）/ warmth=探索・冗長候補（brightness と r=−0.827）。
  **有効帯域=実制作音楽**（純合成トーンでは energy 無相関・brightness レンジ圧縮＝
  K1/K2「センサー盲は素材依存」と同型）。CLI に `--clap-checkpoint`/`--clap-amodel`
  を追加し provenance ピンの CLI 切れも解消。
- **#149 センサー選定 = 歌詞転写（Demucs vocals stem + faster-whisper）**:
  相補性の核＝CLAP は連続値 grip（vocal の有無）を読み、歌詞は**記号列**（何を
  歌ったか）で完全照合可能（R4 chord_sequence_match_rate と同型）。「歌詞=意味層
  アンカーで耳が唯一のセンサー」（07-01）のギャップを機械化し、07-03 S3 の人手
  実証を制度化。入力側 `extract --lyrics`（隔離 annotation・schema 1.2）+ 出力側
  `lyrics-adherence`（検収計器・verdict なし）。PANNs 配線案は CLAP zero-shot と
  重複+順位信頼性×で不採用。ライセンス全チェーン MIT 実確認
  （faster-whisper/ctranslate2/Systran weights）。
- **#149 実推論で 2 つの設計裏付けを実測**: (1) per-line 照合の長さペナルティ欠陥
  （完全転写でも 0.38）を発見し `_partial_ratio`（期待行長ウィンドウ）で是正、
  (2) ハルシネーション判別は **no_speech_prob が有効**（器楽 0.814 vs スピーチ
  0.006）で avg_logprob は無力（−0.067 vs −0.154）＝ per-segment 記録設計の実証。
- **Codex P2 通算 11 件・全 1 ラウンド解決**（#148×3 / #149×8）。#149 の 8 件中
  4 件が **provenance 契約**（model_info パラメータ化→上流 _MODELS 3 段解決→
  プリロードスタンプ→report model 節）、3 件が**順序自覚化の段階深化**（index
  カーソル→文字オフセット→CLI 表示）。上流マッピング P2 では Codex の想定値
  （distil→distil-whisper org）が誤りで、**インストール版の実テーブルを一次ソース
  にする設計が指摘自体の誤差も吸収**した（実際は Systran/faster-distil-*）。
