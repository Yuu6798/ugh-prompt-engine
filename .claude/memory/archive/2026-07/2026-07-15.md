### Design Decisions

- **AR-FB-P0（#181）**: `IdentityManifest.schema_version` は**必須・default なし**
  （新設サイドカー・レガシー無し・欠落を 0.1 と推測補完しない）/
  `PreservationContract` は default 温存（builder 刻印・既存テスト無傷）/
  `format_version` のみ Optional（無版フォーマットに捏造を強いない）。
  M1 表現統一は grounding で「committed docs に過大表現なし」と確定し、
  テストコメント 1 行に縮小（正典文言は #182 の計画文書が担う）
- **AR-FB-DOCS（#182）**: CLAUDE.md 400 行 cap の外出し対象 =「ugh-audit-core
  パターン対応」表（docs/architecture.md の Three-Layer 表と 3/5 行重複、unique
  2 行のみ移設）。Safety Gate は AGENTS.md §8 にチェックリスト集約の既存パターンで
  配置 + §7 に参照 item 11。**計画文書は元ドラフトが checkout に残っておらず、
  memo の escalation 指示どおり停止 → ユーザー承認の上で「確認できる設計契約のみの
  再構成」として収載**（文書冒頭に再構成である旨を透明明記。推測補完せず escalation
  が設計どおり機能した実例）
- **AR3-2（#183）**: repo に前例が無いことを grep で確定した上で
  **artifact_type→チャネル対応表を新設裁定**（lyrics_text→lyrics_text /
  midi_clip→midi / note_events_json→symbolic_melody / audio_excerpt→reference_audio /
  section_map→section_tags / **chord_sequence_json は unmapped→unknown** —
  symbolic_melody への相乗り=発明補完を明示禁止）。`control.status` は常に
  "unknown"（capability≠grip・evidence 源未配線のため捏造しない）、
  `observation.status` は常に "not_observed"（AR4 の欄だけ先に開ける）。
  contract は package CLI が inline 構築（contract 書き出し CLI が未実装のため）、
  artifact は参照+sha256 でコピーなし（builds/ dir は推奨順⑥）、strict 失敗 =
  hard×{unsupported,unknown} のみ（experimental は配送可能）
- **レビュー運用**: #181 は Fable レビュー（指摘ゼロ=予測どおり 0 ラウンド）。
  Codex の Windows ローカルが symlink/CRLF の環境要因で full green を出せないため、
  **Linux clean worktree での独立検証（not slow 1281 passed）を委譲実施して補完**する
  型を確立。GitHub の Approve ボタンは PR 作者と同一アカウントのため使えず
  「Approve 相当コメント」で代替
