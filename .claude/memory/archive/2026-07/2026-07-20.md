### Design Decisions

- **WI 系列の思想 4 点セット**（#197）: 宣言的契約（同一性は作者宣言の履行）×
  弁別判定（絶対閾値でなく順位・対比）× 再構成条件の校正（意味は測らず人間判定を
  基準器に校正）× 被覆の正直会計（verified / not_observed 明細)。Goodhart 抑止
  （proxy は判定器であって生成目的関数にしない）・ラベル先行付与禁止（#196 教訓）を
  事前埋め込み。既存 queue の D-1 閾値 Memo / センサー配線を WI1 / WI0 へ編入
- **WI0 の a/b 分割**（#198/#199）: 実推論（Demucs / faster-whisper / basic-pitch）は
  重 optional 依存のため、配線+synthetic 検証（a）と実測 fixture（b）を分離
  （#149 fake-backend 先行・musicgen PR A/B 分割の前例踏襲）
- **melody v0 は音高系列のみ（時間整列なし）**（#198）: beat↔秒変換は BPM 推定への
  依存＝交絡のため意図的に回避。移調は pitch 低 / interval 満点になる設計を pin
- **事前登録の採否ルールを初適用**（#199）: 計測前に `date -u` 付きで
  「faithful レンダーで pitch_lcs_ratio ≥ 0.8 なら WI2 v0 採用候補」を固定 →
  実測 0.6 < 0.8 で **melody 軸を WI2 v0 から除外**（事後変更なし）。原因判読:
  basic-pitch は全ミックスを正しくポリフォニック採譜しており、盲目なのは
  v0 比較設計（全ミックス採譜 vs 単旋律正典・分離層なし）でセンサー品質ではない。
  **再入条件**=旋律分離層導入後に再計測 ≥ 0.8
- **lyrics のゲートは転写文でなく no_speech_prob 側**（#199）: instrumental 入力で
  Whisper が no_speech_prob 0.92–0.94 と自己申告しながらウェールズ語
  ハルシネーション文を emit（abstain しない）。overall_similarity 0.0056 →
  not_observed/deferred は計器の正しい動作＝#149 知見の実測追認。精度実測は
  素材律速（歌入り+歌詞 pin 音源なし）で defer
- **#195 規律の即日自己適用**: #196 の emit 前 pin 検証（manifest / package /
  section_map / repo 正本 / 4 take audio sha 全数一致）が「provenance 成果物は
  全入力 pin 検証接続後に emit」規律の適用第一号
