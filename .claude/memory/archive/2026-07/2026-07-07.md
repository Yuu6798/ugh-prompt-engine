  (1200, 2500) Hz と centroid 欠損が同じ `None` → TODO センチネンルに合流している

  （fixity locked・YAML 往復 pin）へ昇格し、センチネルは

  dead branch は削除し、汎用 `is_todo_sentinel` prefix 判定でレガシー文字列の
  後方互換を担保。

  「neutral=TODO 前提の叙述ブロックが恒久 dead 化」に対し、#154 の honesty
  掃引規律（発火不能な説明叙述を残置しない）を適用して削除と裁定。
  docs/musicgen_backend.md の過去実測記録は dated log 保全で不変更と裁定。

    `_neutral_band()`（dark/bright ルールの間隙から動的導出・ハードコードなし・
    欠落時 undefined フォールバック）を採用。
