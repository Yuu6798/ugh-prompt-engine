### Design Decisions

- **PR1（#120）control_profile スキーマ**: `fixity` パターン踏襲だが**網羅必須は引き継がず疎を
  許容**（K2 の Suno は bpm/brightness の 2 フィールドのみ）。`ControlGrip`(grip_class 必須/
  grip・sensor・evidence optional・空なら非 serialize)、未知 field fail-fast、K2(#117) を初期データ投入。
- **PR1.5（#121）control_profile-aware compile**: **tight フィールドを先頭へ昇格**（描画順は AC 外で
  裁量 → ユーザーに質問し「先頭昇格」確定。Suno が先頭 Style 語を強く読む製品仕様 + ロードマップ
  「優先描画・芯」に整合）。フィールド粒度 drop accounting（`physical.optional` 束を 4 フィールドの
  独立文へ分解・ID は PhysicalLayer 正式名）、backend selector(`external`→`suno`)、priority エイリアス
  マップ、backend descriptor 隔離。brightness の `semantic.core` 重複を除去しフィールド単独所有へ
  （独立 keep/drop 成立のため）。
- **PR1.5 レビュー Codex P2×3 全対応**: ①`semantic.core` の `.capitalize()` 退行（"AI EDM"→"Ai edm"）を
  `_sentence_case`（先頭1文字のみ）へ ②tight な `time_signature` が未描画の穴 → フィールド粒度
  セグメント追加 ③`GeneratedPrompt.backend` が musicgen でも "external" 固定の誤ラベル →
  `_generated_backend` で選択 backend 反映。各回帰テスト追加・スレッド resolved。
- **PR2（#122）score-adherence test — スコープを絞る判断**: ロードマップ PR2 は「楽譜準拠テスト
  + CLAP」だが、**CLAP は torch + 2GB 重みを引き本環境で実検証不能・`learned_models_policy` の
  adopt リスト外**。依存ゼロで確実に完走できる**楽譜準拠テストに限定し CLAP を PR2b へ分離**
  （既存 beat_this/panns の spike 分割流儀に踏襲）。tight 宣言を 2 側面（compiled_kept=PR1.5 の
  drop されない保証 / preserved=roundtrip 4 値診断）で照合。**計器であって verdict ではない**
  （グローバル pass/fail なし、件数のみ）を audit/roundtrip 同様に貫徹。backend selector を PR1.5 と
  共有し path 非依存（決定論 performer でも実 Suno take でも判定可）。
