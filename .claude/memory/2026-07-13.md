- **M2 の位置づけ = 再計測 + 既知交絡 2 件の解消**: (a) valley 床 0.078 は素材制約か
  ツマミ死か → 30.6s でセル値据え置き・素材長のみ変更して分離。(b) active_rate 天井
  （low 0.55 で観測 0.967）→ low 処方を 0.30 へ拡大して headroom 確保（事前登録で理由明記）
- **判定（Fable 裁定）**: active_rate **loose 確定** d=0.414（天井解消後も旧 0.394 と
  同値＝アーティファクトでない）/ valley_depth **dead→loose 昇格** d=0.352（旧 dead は
  12s 素材制約との合流と確定）/ time_signature **dead**（事前登録ヌルゲート発火。
  combined 0.5625 の機械分類 loose を棄却・3/4 初達成 1/8 は記述的所見・帰属未分離）。
  canonical 3/3（補充ゼロ・秒単位 UTC 実測・fresh-process sha256 スポット 2/2 一致）
- **1 コマンド = 1 クリップの実行様式**: runbook に `--only-knob` を新設し
  `--only-level/--only-repeat/--append` と併用、1 クリップ ≈ 3.6–5 分を Bash 10 分
  上限内の同期実行に収める（委譲停滞の構造的回避、実際に 48/48 無事故で機能）
- **#173 は user が対応 push 前にマージ** → merged-PR 規則どおり main から同名ブランチ
  再作成 + cherry-pick で follow-up **#174** に分離
- **#174 = Codex P2 全 8 ラウンド全採用でヌルゲートが原理化**:
  ①`≤`ゲート（K1 key 1.0/1.0 tight を誤殺→コミット前検分で捕捉・修正）→ ②strict `<`
  + 等号は静的説明可能性（和 ≤ 1）→ ③high セル tight 免除（1.0/0.875 の誤殺防止）→
  ④markdown 既定出力に gated 列可視化 → ⑤fuzzy スコアラー対応 1+cross_score 境界 →
  ⑥**和境界は必要条件のみ**と判明し**観測 multiset 同一性**（静的出力の観測シグネチャ
  そのもの）へ置換・和境界は観測リスト欠損時フォールバックに降格 → ⑦multiset 比較に
  スコアラー同一の正規化 → ⑧key は異名同音等価（半音+モード、keys.py 既存パーサ再利用）。
  到達原理 =「**等価関係は常にアクティブなスコア関数と一致させる**」「**計器は最強
  シグネチャのみ自動格下げし、灰色は per-cell 併記で人間裁定へ**」
- **バッチ事前登録は計器既定に優先**（バッチ局所 decision rule > 計器の一般化既定）を
