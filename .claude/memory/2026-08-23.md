  run4 sha256 と **6/6 バイト一致**。(a-1) の定めどおり item 1 は measured_only

  GPU ≠ CPU）/ F3=対照の取れた ritsu 2 曲では一致/不一致が device のみで反転
  （2/2 vs 0/2。当初 6/6 vs 0/2 と書き Codex 指摘で対照範囲へ限定）/ F4=GPU

- **障害 2 件を実測診断で根治**: (1) run 1 の回収失敗 = RunPod proxy 前段
  Cloudflare の `Python-urllib/*` UA ban（error 1010）。最安 CPU pod（$0.01）の
  チャネル単体実験で UA 分離により確定 → 全 urllib 呼び出しへ UA 注入。
  (2) run 2 = nvidia-smi 成功でも venv の CUDA init が落ちるホスト依存事象 →
  CUDA 診断ステージ + 3-way ゲート（system torch フォールバック）を組込み
- **回収系の設計原則を確立**: 回収窓は t=0 常時 serve（課金消費後にしか疎通検証
  できない構造を排除）・volume 保険・stop→回収→delete 順序・**成功条件の要求
  集合は閉世界契約（固定定数）で書く**（transport/record 由来の要求集合は
  空洞化し得る — Codex 第 2〜5 巡が同型穴を連鎖指摘し、第 5 巡で構造終端）
