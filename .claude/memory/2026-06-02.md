  小文字化 + アルファベット順ソートされ、grv の primary/secondary 優先順位・structure の

  `CompositionScore` を直接読む設計とした（順序・case 保持）。
- **C2 で 3 不整合を正規化**: ① `GeneratedPrompt` を brief §12 正規形
  (`backend/text/tags/negative_tags/dropped_elements`) に再定義（C1 の char_count 版を置換）、
  ② examples をディレクトリ形式 `midnight_signal/composition_score.yaml` へ移行、
  ③ renderer 入力を CompositionScore に固定。
- **圧縮アルゴリズム**: text を `rendering.priority` 順セグメントで組み、priority 未掲載要素
  （avoid 等）を最下位として最初に drop、token 名を `dropped_elements` に記録。
