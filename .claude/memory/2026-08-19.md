### Design Decisions

- **学習回路 VG-L0**（User 洞察「交配は声を作るが歌い方は教育が要る」が
  動機）: 書き込み先 = 制御層採用 / spk_embed は現行アーキテクチャで却下
  （disentangle 時再審査）/ Adapter は天井実測後。自律性 Level 2 は
  **制御軸単位で解禁**。TRANSFER_SKILL（教育）を第 3 の Edge 種として
  語彙化（構造的 Identity 非変更は構成保証・知覚的 drift は Identity audit
  必須）。決定性は Transition / Render の 2 層分離。成果の過大定義禁止
  （held-out 1 曲 = 「別曲転移の初観測」まで）。H16 = 交配/学習分離で
  Quality Floor 到達率改善 × Identity 多様性損失の抑制（S2 0/10 の
  再解釈仮説・④の素/稽古後二重判定で無料検証）
- **SPR（Selection Pressure Routing）**（User 叩き台・早期整備 = 手戻り
  最小の裁定）: 一回路一主選択圧・回路別淘汰単位（個体/Revision/Lesson/
  世界）・評価値 G/A/R/D 4 分類（2 制約 + 1 主圧 + 1 発達形質・
  Developmental は Behavior Descriptor で繁殖点加算禁止）・強度順序
  P_birth < P_T ≲ P_L < P_E・隔離規則 7 件。**最重要の即効条項 =
  「繁殖圧→出生への漏れ禁止」: ④第 0 世代の審査は行 1 の弱 viability
  圧のみ**（S2 型誤配線疑いの再発防止）。理論正本 = 補論 A / 配線契約 =
  DESIGN_SPR の二層
- **Trial 層 VG-TR0**（User 叩き台）: Birth/Development と Evaluation の
  間の観測層。「Trial は試験・Evaluation は採点・Selection は処遇」の
  三分離（audit=計器原則の生態系版）。Suite 6 群・schema 5 種（新系列
  台帳・VG-E0 非改変）・Failure Profile = 表現型マップ・禁止 10 項。
  五段完成: **産む→育てる→試す→測る→選ぶ**
- **レビューでの実装事故の先取り 2 件**（VG-TR0 照合）: ①gate_synth run は
  既定で ONNX export/publish が走り「状態を変えない」契約が破れる →
  --skip-export 強制 + state hash 検査が検証器を兼ねる構造に。
  ②load_song_module は SCORE_REGISTRY 非参照・sakura/umi ハードコード →
  song loader 拡張を実装第 1 タスク化
- **文書間の主張強度の増幅**を定点観測項目化（「S2 誤配線の疑い」が
  伝播先で「禁止」に強まっていた事例を照合で検出・格下げ）
