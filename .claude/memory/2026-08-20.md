- **中核の知見 = 制御パラメータは単調・音響応答は非単調**: 子音比は入力係数
  どおり 0.0562→0.4167 と滑らかに動くのに、RMS は非単調（×0.25 が ×0.5 より
  高い / ×3.0 が ×2.0 より低い）。→ グリッド設計は解析的にできるが**知覚順序は
  予測できない**ので、DESIGN_VG_L0 の「稽古 = 選抜（耳の順位付け）」方式は
  妥当。勾配・補間で最適値を推定する方式はこの非単調性の上では成立しない
  （ただし RMS は粗い代理指標で、非単調が知覚レベルでも成立するかは未検証 —
  評価軸選定は VG-E1 と合流）
- **構造的発見**: アタック軸のみ**総尺不変**。ブレス/終端は総尺が変わるため
  楽譜と干渉する → profile schema v0 は総尺不変軸と可変軸を**型で区別**する
- **SB0 発動条件への入力**: 3 軸 × 4 水準 = 12 テイク/遷移。総当たりペア比較
  なら 18 ペアで発動条件（10〜12 ペア超）を超えるが、DESIGN_VG_L0 が指定する
  ブラインド**順位付け**なら 3 セッションで済み未達。**実施形態が判断点**に
