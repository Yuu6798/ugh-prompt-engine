## Design Decisions

- **K3 の統計を「全セル = 既存 grip_effect_size（符号付き Cohen's d）」に統一**。
  ランダムドリフトは pooled SD（分母）に吸収され系統的干渉だけが非対角に立つ。
  key は「ベースライン key への mir_eval 一致スコア」で連続センサー化
  （low 水準 = ベースライン、expected_sign=−1）。K1 の categorical 一致率は
  対角 informativeness として温存（置き換えない）。
- **DCI の効果量再定義**: importance = |d| を floor 0.2（dead 閾値 = ノイズ
  フロア）/ cap 10（飽和センチネル ±999 の正規化支配防止）。disentanglement =
  1−行エントロピー / completeness = 1−列エントロピー / 質量加重 overall。
  **MIG は「効果量ギャップ」と正直に命名**（相互情報量ではない）。
- **エイリアスセンサー問題**: 同一潜在因子を読む別センサー（bpm↔onset_density）を
  DCI 正方コアに入れると disentanglement が偽って下がる → コアはツマミ 1:1 の
  正方に限定し、extended 列（行列表示・干渉分類のみ、DCI 集計除外）へ隔離。
- **SEM-1 lyrics_presence は SemanticLayer 配置**（PhysicalLayer ではない）:
  (a) 歌詞は意味層アンカー、(b) fixity の physical 全網羅制約を壊さない、
  (c) 決定論 performer はボーカル描画不能で恒久 dead 誤読を生む。control_profile
  許可キーは `SEMANTIC_CONTROL_FIELDS` ホワイトリストで拡張（fixity は不変）。
  **初期 Suno プロファイルは loose 固定**（honesty: mid_ratio の noise 超えは
  Rock のみ）。tight 昇格ゲート = n≥2×2 セル + K3 干渉分離、を docs に制度化。
- **K3-2a は「新規生成ゼロ」路線**: K2 fixture が全センサー per-sample 記録済み
  と確認 → 決定論 JSON 変換だけで本物 Suno の 2×2+3 行列を実測（人手律速を回避）。
- **確度の階層を明示する規律**: K3-2a の解釈は (a) 対角の K2 再現 = 高確度 /
  (b) 集計パターン = 中 / (c) セル単位の結合 = 未解決（R=4・dead 行なし、
  K3-1 ノイズ天井 |d|≲2.5 内）と分けて記述。#124 の「効果>再生成ノイズ」基準の
  行列版。

### Design Decisions

- **デバイスプロファイル（#128）**: 機種の癖はスコアでなくリポジトリレベル知識 →
  `config/device_profiles/suno.yaml`。コンパイル接続は (a) control_profile 欠落の
  device 既定補完（score 宣言が常に勝つ）+ (b) advisories（**本文・tags 不変**=
  自動補正しない）。advisory は CLI text 出力で stderr へ分離（成果物純度、Codex P2）。
  cross_couplings は全 status=unresolved で advisory 非発火（誤って補正済みの印象を
  与えない）。adherence 非対称（device 既定 tight は判定対象外）は未決として docs 明記。
- **K3-1b（#129）**: ヌル分布の出所は**宣言**（fixture `known_dead`、配線非実在は
  コード検査で既知）であって推定でない — spurious loose の dead 行こそ最良のヌル。
  天井 = dead 行全セル（対角含む）max|d|、各セルに noise_margin。dead 行なし fixture
  では ceiling=None=全セル unresolved を**計器自身が申告**。DCI 不変（注釈レイヤー）。
  機械判定の resolved セルが §5.3 の散文判断と完全一致＝昇格の検証。
- **PR2b-1（#130）**: CLAP を learned/ 確立パターンの複製で隔離配線。similarity は
  numpy のみ（fixture 上で完全動作）。ライセンスは verbatim 記録（PyPI license=CC0 全文
  vs classifier=Apache の上流内部矛盾・weights は HF 403 で要確認）。レビューで
  **rand_trunc 非決定論を「構造による決定論」で潰す**（自前デコード→窓長以下チャンク→
  平均、RNG シードは上流依存で脆く不採用）。Codex の「exact-size で UnboundLocalError」
  指摘は **PyPI wheel 実物で反証**（else レベルで longer 代入・`# do nothing if equal`）
  — 一次ソース検証が不要な複雑さの混入を防いだ。amodel 貫通（music checkpoint は
  HTSAT-base 必須、README 裏取り）。audio_sha256 pin 照合を collector に追加。
- **PR2b-2（#131、Codex 実装）**: Fable Design Memo → Codex PowerShell 実行。
  実測: **CLAP vocal contrast が「効果>再生成ノイズ」を両ジャンル充足**（EDM 15×/
  Rock 12×）— 意味層に初の機械センサー。レビュー 8 スレッドを並行分担で消化:
  checkpoint_sha256 pin（Fable 設計判定→Codex 実装→Fable 検証）、materialize 文書化

  （Fable 直接 push bef21f3 — 上流 1.1.7 の install_requires 不備、「extra が torch
  境界を運ぶ」契約を真にする方を選択）。
- **相互検証①（#132）**: 生成・推論ゼロ — #131 fixture × #124 計測ログを
  audio_sha256 突き合わせ（6/6 リンク）。**条件レベルの方向は両センサー完全一致**
