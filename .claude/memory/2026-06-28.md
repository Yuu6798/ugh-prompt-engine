### Design Decisions

- **#107: 計器＋回帰ガードで「magnitude も合成器では盲」を固定**。実測値: power high_ratio≡0.0、
  magnitude brilliance≈0.018 で非ゼロ floor を持つが grip span≈9e-4 で平坦＝dead。ノブの
  エネルギーは magnitude `mid`(500-2kHz, 0.26→0.43)へ流れ centroid だけが live sensor。
  含意: orchestral/rock/EDM の brightness 分離は合成器では検証不能で R1-audio 必須、を計器側から
  裏付け。production semantic_rules は不変。
- **#108: 閾値変更でなく measured な据え置き判断**（#106 BPM finding と同型）。seed pair
  separability 実測:
  - power `low_ratio`: 全ペア overlap（全 >0.4）＝判別器でなくゲート。
  - power `mid_ratio`: 全ペア overlap（かつ production mid-focused 閾値 0.45/0.5 に seed が
    一度も届かず＝ルール未発火）。
  - magnitude 低域: `bass` 全ペア overlap、`sub_bass` rock↔EDM のみ、`low_mid` orchestral を
    rock/EDM から分離（rock↔EDM overlap）＝いずれも部分的。**全 3 ペア単独分離は brilliance のみ**
    (d 3.3–7.0、B-3 済)。
  - 結論: 高域は #91 で power defective だったため B-3 magnitude 化が必須だったが、low ゲートは
    power 健全で是正動機なし・ゲート境界(低域厚 vs general)の magnitude 再導出には seed に欠く
    general アンカーが必要 → **`low_ratio` ゲートは closeout（power 据え置き）、`mid_ratio` は
    評価不能で繰越**。
- **honesty caveat（Codex 指摘で深化）**: 実アンカー portals は scalar `low_ratio` のみ持ち
  mid_ratio/spectral_bands 未計測。非 null のみ比較のため magnitude 判別軸と mid_ratio の所見は
  **全ジャンル Suno のみ（実アンカー grounding ゼロ）** → Phase C はゲート境界拡張だけでなく
  magnitude 軸の generator bias 検証にも必須。

## Session 2 — 2026-06-28 (Genre Calib Phase C 着手: 本物 vs Suno generator bias)

### Context

掘り下げ、**Genre Calibration Phase C を 3 PR で一気に前進**させた。中心テーマは「Suno 生成音源で
校正してきたが、Suno は本物とどう違うか（generator bias）」の実証。ユーザーが実音源を提供
（実 J-POP → 推奨に基づく lossless 購入）し、Claude が extract → 比較 → finding 化の協働フロー。

- **#109**: 実 J-POP 3 本(安室/SPEED/湘南乃風)を `genre_label: j-pop`/`generator: real` で登録。
  repo 初の実 grounding spectral_bands。bias 初観測だが Suno EDM と比較＝ジャンル交絡あり。
- **#110**: 同ジャンル・同キー・同 BPM の Suno を対生成(matched-pair)し交絡を排除。
  over-brightening を genre-controlled で確定。
- **#111**: 本物 orchestral/rock/EDM 各1本(Star Wars/Nirvana/Daft Punk, lossless)で
  「指紋はジャンル横断で一定か(=補正係数化できるか)」を検定。

### Design Decisions

- **本物音源ワークフロー(licensing 回避)**: audio は repo に commit せず measured+full sha256 のみ
  保全(Portals/R1-audio 方式)。「licensing 律速」は実は過大評価で、本当の律速は「本物を extract に
  通す人手」だけ、と整理。lossless 必須(brilliance=6-20kHz が主役、lossy 高域ロールオフが汚す)。
- **m4a/mp3/FLAC 取り込み**: ffmpeg 不在環境で `pip install imageio-ffmpeg`(静的バイナリ)で
  WAV 化。FLAC は soundfile が直接読める。
- **Drive 取得は不可と判明**: Drive 直 DL は egress policy で 403(回避禁止)、MCP download は
  base64 インラインで MB 級不可。→ ユーザーが 90 秒 lossless FLAC クリップを直接添付する方式に。
- **matched-pair プロンプト**: Suno が実在人物名("Tetsuya Komuro")/レゲエ奏法語("skank")を
  アーティスト名フィルタで弾く → 音響記述に置換して回避。
- **bias の核心発見(当初仮説の反証)**: brilliance over-brightening は **ジャンル一定でない**
  (orchestral/EDM=Suno と一致、rock/J-POP=Suno が明るすぎ、符号反転)。→ 単一補正係数は不可。
  代わりに **方向一定の指紋を 2 つ発見**: ①中域削り(mid_ratio 本物>Suno 全ジャンル)
  ②トーナル化/脱パンチ(harmonic_ratio 本物<Suno 全ジャンル, EDM で最大 −0.43)。
  = Suno は「ドンシャリ + ツルツル」加工をかける(プリクラの盛れ加工の比喩)。
- **ゲートの一般化限界(ボーナス)**: 本物 Star Wars の low_ratio=0.388<0.4 で `low_ratio>0.4`
  ゲートを通らず general 落ち。#108 で「健全」とした low ゲートは Suno が管弦を人工的に低域厚に
  描いていただけで、本物管弦(中域主役)には一般化しない。
