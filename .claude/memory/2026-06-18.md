### Design Decisions
- **bpm を確率的経路（R3）の信頼再現ノブから明示除外** を closeout の確定結論とした。
  根拠: faster-side（reported-too-slow / halving）は #82–#85 の検出器系列で post-hoc
  に部分緩和（近傍探索化 + reported bpm 回復補正 + confidence cap）したに留まり、
  principled fix（tempo prior 適応化）は高回帰の別タスクで OUT。÷2（reported-too-fast
  / doubling）は #86 で AC 振幅 / beat-phase 交替 / 単独低 prior の 3 手法いずれも
  extractor では分離不能と実測反証（pad の synth_01 は交替最弱・正検出曲を巻き込む）。
  → 「送出かつ計器が信頼できる物理ノブ」（完成定義 §3 = key / brightness）に bpm は
  含めない。
- 除外は**廃止ではない**: bpm は (a) 決定論経路（R0）の三値診断で計測・
  `calibration_disagreement` として正直に surface、(b) corpus screener の prior 回復
  診断（stated 真値必須）に観測対象として残置。R3-2 が元から key/brightness 限定で
  あった事実とも整合し、暗黙の除外を明示化しただけで矛盾を生まない。
- §4 の「フォールバックは未確定でなく除外確定」契約に沿って終端状態を確定した。
- R2-3（T0 per-field 校正メモへの反映）は roundtrip_preservation.md の K1 Cross-Check
  bpm bullet + Follow-Up Routing に per-field bpm trust として記録（往復ハーネスの
  三値診断に「この針はどこまで信用して bpm を転記できるか」が効く）。
