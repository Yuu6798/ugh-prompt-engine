## 誤差モデル（M3 の目盛りの根拠・4 軸）

**1. 音高中心誤差（cent）** — 有効帯域では小さく安定。合成 ~1.4 cent・実声
per-clip median 2.33–6.91 cent（中央 3.65）。**注意（打ち切り統計）**: この median は
`accuracy.py` の実装上、50 cent chroma 基準を**通過したフレームのみ**から算出される
打ち切り値であり、除外された残差と受理側上位半分の裾は写っていない。したがって
「±50 cent の標準許容内で中心誤差は 1 桁下」までが本実測の主張であり、**M3 が許容幅を
50 cent 未満（例: ±10–15 cent）へ狭める場合は、候補許容幅での RPA 再計測
（打ち切りなしの残差分位点の取得）を先行条件とする**。

**2. オクターブ誤り率（RCA−RPA）** — direct 帯では実質ゼロ（集計 0.15%・
最悪 clip 2.54%）。M3 のオクターブ正規化は必須ではないが、**worst-case 2.5%/clip の
予算**として計上する。**注意（片側観測）**: この率は「1 本の抽出 vs 正解」の
片側観測であり、M3 が両側とも抽出系列の対比較を行う場合は両側の誤りが独立に
乗るため、対不一致は最悪 ~2 倍（cent 残差も両側合成）になりうる — 対比較予算と
して使う前に**両側誤差分布の導出 or 実測**を要する。分離込み（S-fullstack）でも
0.33% と低いが、これは
「octave 型の誤りが稀」という事実に限られる — 同帯の RPA 0.640 / RCA 0.643 は、
検出有声フレームの相当数（参照有声比 ~26%）が 50 cent chroma 基準さえ外すことを
意味し、**分離は音高追跡自体も損なう（または別ソースの追跡に流れる）**。ただし
S-fullstack は合成音色が demucs の分布外の診断値であり、この観察から分離の
因果的帰属は行わない（実ミックスでの評価は V-fullstack 実測待ち）。

**3. voicing 誤検出（VFA）— 本経路の系統的弱点軸**。**direct 帯**では VR ≈1.0
（S-direct 1.000 / V-direct 集計 0.998。ただし取りこぼしは**小さいが非ゼロ** —
per-clip VR は 1.0 未満の clip が複数あり最小 ~0.987）に対し、VFA は S-direct
0.259・実声 median 0.44・**per-clip 0.13–0.76 と分散の主軸**。なお S-fullstack は
VR 0.903（参照有声の ~9.7% を取りこぼす）で、「取りこぼしなし」は direct 帯限定の
観察 — 分離込みでは voicing 誤りを false alarm だけに畳めない（分布外診断値として
記録）。S-direct fail の帰属仮説（休符のリリース尾 = spec 上無声・音響上有声の
正解境界アーティファクト）について: 実声の集計 VFA はこの仮説と**矛盾しない**が、
commit 済み記録にはフレーム位置の局在情報がなく、ブレス・ノイズ・注釈境界など
別因でも同じ集計値は生じうるため**原因は未検証のまま**とする（局在誤り分析は
将来作業）。後述の候補アプローチの根拠は「原因が何であれ抽出器の voicing 判定は
信頼できない」という実測事実であり、リリース尾仮説の真偽には依存しない。**M3 への含意（最重要）**:
本実測が確定するのは**リスクの記録**まで — (i) 抽出器の voicing 判定は信頼できない
（VFA 高・分散大）、(ii) 一方で voicing を無視した比較は削除/移動区間を見逃す
被覆穴を作る。この 2 リスクを同時に扱う**候補**として「両系列が共に有声の
フレームのみで音高比較 + voicing 不一致は非ペナルティ」を推奨するが、比較
アルゴリズムの確定は M2 スコープ外（設計 §0/§9）であり、**採否の判定は
M3 Brief の User 承認に委ねる**（整列意味論の定義・本方式の安全性検証を含む）
（est_voiced_confidence_floor 0.30 は凍結値・事後調整禁止）。**被覆損失もリスク
として記録する**: 共有有声フレーム限定は「歌唱区間の削除・オンセット移動・部分
重複」を評価から消しうる（僅かな重複残存での過大類似）。対策候補は joint-voiced
被覆率（IoU 相当）の独立信号併記 + 被覆下限ゲートだが、**分母・整列意味論・閾値は
未定義・未校正**であり、同じ voicing 判定から計算するゲートは VFA 分散の影響も
受けるため、指標定義と閾値校正は M3 Brief 側の導出・検証に委ねる（本書は要件化
しない）。

**4. 素材別ばらつき** — 実声 40 clip で RPA min 0.9507（バー割れゼロ）と音高は
一様に高い。ばらつきは VFA に集中（録音デバイス・歌唱密度依存と推定）。
**注意**: per-clip VFA は正解 voicing ラベルとの照合で定義される**校正コーパス限定の
統計**であり、正解なしの M3 入力では計算できない — これを推論時の信頼重みには
使えない。推論時に使える proxy（例: 抽出器 confidence の統計量）を重み付けに使う
場合は、その proxy の定義と校正（本コーパスの VFA との対応付け実測）を M3 側の
先行作業とする。集計は per-clip 算術平均（clip 等重・MIREX 慣行）。

**計器ノイズ床**: 同一バッチ内 repeats は bit 一致（commit 済み verdict の
`repeats_bit_identical` が根拠）。バッチ間については、M2b セッション記録に median
cent の ~1e-3 cent 双安定（TF CPU 推論由来と推定）の観察があるが、**commit 済み
記録には片側の値（1.353400）しか存在せず未確認** — 先行 6 回は非 commit
（m2b README 参照）のため、この観察は誤差モデルの確立済み境界としては扱わず、
「同一バッチ内 bit 一致はバッチ間決定論を含意しない」という**注意書き**に留める
（確立するには対照条件の第二バッチ記録の commit が要る）。

## 帯域地図と §7 分岐判定

- **crepe_direct（clean lead / vocals stem 入力帯）**: **実測済み・誤差特性付き**
  （音高系は合成・実声とも高精度、voicing は上記の既知バイアス）。**「calibrated」
  認定は下記 §7 決裁の結果に従属し、本 doc は認定しない**（S-direct fail が
  記録されている限り、決裁前の calibrated 表記は §7 文言と矛盾するため）
- **demucs_vocals_then_crepe（フルミックス入力帯）**: **未校正**。S-fullstack は
  合成音色が demucs の分布外のため診断参考のみ（RPA 0.640 を経路の欠陥と読まない）。
  V-fullstack は MedleyDB 確保後に dated 再入
- **§7 分岐の判定は User 決裁待ち（本 doc は判定を先取りしない）**。記録された verdict
  の組（S-direct **fail** / V-direct pass / V-fullstack 未測定）は §7 のどの分岐にも
  正確には一致しない: 文言どおりなら S-direct 不通過は「crepe を calibrated 候補から
  外し（一方向）代替抽出器の再入を待つ」だが、その分岐の想定（経路自体の不信）と
  実測の帰属（音高完璧・fail 因子は voicing 単独 = 正解境界アーティファクト疑い）は
  緊張関係にある。選択肢は (a) 文言どおり M3 非前進（代替抽出器での dated 再入を
  待つ。なお「正解境界の修正による S-direct 再挑戦」は正解=凍結 specs の変更であり、
  one_way_rule の許す「経路/実装の変更」に該当するかの**解釈自体が User 決裁事項** —
  無承認では失格経路の事後救済に当たりうるため本 doc は選択肢に含めない）/
  (b) §7 を「音高系と voicing 系の撤回範囲を分離する」
  形へ **User 承認の上で改訂**し、stem/clean lead 入力限定の M3 先行を許可 — の 2 択で、
  **M3 Brief 起草前に User が決める**。§4 の「calibrated 昇格 = V_fullstack 通過」が
  未達である事実はどちらの選択肢でも不変（フルミックス帯への外挿は禁止のまま）
